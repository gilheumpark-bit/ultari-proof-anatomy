## 0. Preamble & Operational Scope

### 0.1 Five International Academic Reference Guidelines Synthesized Under One Rubric

All mathematical and technical audits in [`ultari-proof-anatomy`](./README.md) are evaluated against a **5-Gate Audit Rubric** (`Open Proof Forensic Framework`, `OPFF`) synthesizing published guidelines from five international academic communities across publication ethics, pure mathematics, formal verification artifacts, authorship transparency, and machine learning reproducibility:

1. **COPE** (*Committee on Publication Ethics* : *COPE Core Practices*, *Retraction Guidelines*, *Position Statement on Authorship and AI Tools*)
2. **IMU / AMS / EMS** (*International Mathematical Union*, *American Mathematical Society*, *European Mathematical Society* : *AMS Ethical Guidelines* & *IMU Best Practices for Journals*)
3. **ACM / SIGPLAN** (*Association for Computing Machinery* : *ACM Artifact Review and Badging Policy v1.1*)
4. **ICMJE / NISO** (*International Committee of Medical Journal Editors* & *ANSI/NISO Z39.104 CRediT Taxonomy* : *ICMJE Recommendations on AI-Assisted Technology*)
5. **NeurIPS / ICML / ICLR** (*Three Major AI Conferences* : *Code of Ethics* & *Paper Reproducibility Checklist*)

### 0.2 Methodological Rationale: Four Blind Spots and Large-Scale Proof Auditing

Although frontier AI laboratories have begun releasing formal verification (`Lean 4`) corpora and mathematical preprints spanning tens of thousands to millions of lines, traditional academic oversight lacked an automated cross-check workflow due to **four intersecting technical blind spots**:

1. **The Assumption That `"0 sorry = Specification Conformance"`**:
   A formal proof kernel (`Lean 4`) checks only type syntax and inference rules. By design, the kernel cannot detect whether a submission sets an unreferenced core premise (`_hcomputable` in `#376`) alongside unimported non-zero-pressure modules (`650/1,004`), truncates a public comparator specification to a unary `L`-only space bound and finite prefix table (`#378`), strips an upstream author notice via whitespace preprocessing while placing 46 files inside an external namespace (`#005`), or writes one proof in the LaTeX manuscript (complex curve residues, ODE flows along vector fields, and Lazarsfeld's open cone citation) while formalizing a different algebraic mechanism in Lean (field extensions/traces, algebraic stalk Hasse–Taylor maps, and slope-ODE differential inequalities in `#017`).
2. **Capacity Limits of Manual Peer Review Under Multi-Million-Line Volume**:
   While human referees require months to verify a single 20-to-30-page manuscript, industrial AI pipelines deploy parallel worker swarms (`W06`~`W64`) to generate 95,000 to 7,528,000 lines of proof code per corpus.
3. **Need for Triple-Intersection Auditing (`Pure Mathematics` $\cap$ `Formal Kernel Engineering` $\cap$ `Large-Scale Static Analysis`)**:
   Auditing these artifacts requires simultaneously reading algebraic geometry / analytic number theory proofs, tracing `Lean 4` import graphs and `.patch` external-namespace placements, auditing 55/64 (85.94%) specification hook/panic substitutions vs compiled ELF machine code (`9`, post-PR #2 `19`, symbols directly verified), and orchestrating parallel static/mutation verification pipelines.
4. **Independent Reproducibility**:
   Because many academic computer science laboratories depend on compute credits or sponsored grants from frontier AI corporations, an independent, conflict-free open-source verification methodology is needed to audit public formal verification claims down to exact source lines.

Consequently, **large-scale parallel proof generation (`Swarm`) requires reproducible artifact auditing (`Automated Proof Forensics`)**. This document defines the evaluation criteria used across this repository.

### 0.3 Project Scope & Functional Separation (`Open Proof Forensic Framework, OPFF`)

To provide a uniform, deterministic audit rubric across the cases in [`ultari-proof-anatomy`](./README.md), this repository organizes its detailed technical reports (`05_*`) and summary scorecards (`06_*`) under the rubric label **`Open Proof Forensic Framework` (`OPFF`)** (maintained independently by Gilheum Park as a public technical evaluation rubric of `ultari-proof-anatomy`, not an incorporated foundation, regulatory body, or standards organization):

* **Rubric Label (EN)**: **Open Proof Forensic Framework (`OPFF`)**
* **Rubric Acronym**: **`OPFF` (Open Proof Forensics Framework)**
* **Core Mandate**: Byte-level, zero-truncation technical auditing and 4-tier classification (`TIER S` ~ `TIER F`) of human and AI formal verification artifacts (`Lean 4`, `Coq`, `Isabelle`, etc.), mathematical/scientific preprints, and reasoning traces.
* **Zero-Conflict & Reproducibility Clause**:
  1. The maintainer accepts no donations, sponsorship grants, consulting fees, or compute credits from audited frontier AI corporations (`OpenAI`, `Google DeepMind`, `Anthropic`, `Meta`, etc.).
  2. Every standalone reconstructed proof (`proofs/*.lean`), symbolic/forensic verification script (`proofs/verify_*.py`), universal hypothesis mutation-kill verifier (`tools/verify_all.py`), upstream reference snapshot (`oai_ref/`), and cryptographic digest ledger (`manifest.json`, `MANIFEST.sha256`) required to verify any rubric evaluation is published open-source in this repository.
