## 2. 5대 핵심 질문 (Q1 ~ Q5)

### Q1 (사후 조판 파이프라인의 물증): 공개된 10편의 PDF가 날것의 추론 로그가 아니라 사후 편집본이라는 물증은 무엇인가?

### Q2 (양방향 참고문헌 교체 기전): 추론 로그에 적힌 참고문헌 332건 중 왜 230건(69.28%)이 최종 논문에서 빠졌는가?
모델은 실제 추론 과정에서 선행 논문 332건(#087 67건, #102 56건, #287 54건, #159 53건 등)을 호출해 부분 귀착, 매개변수 스케줄, 막다른 경로 배제를 수행했습니다. 물론 수학 연구에서 실패한 탐색 경로의 문헌을 최종 논문에서 덜어내는 일 자체는 자연스럽지만, 실측 데이터는 단순한 실패 경로 정리를 넘어선 두 가지 비대칭을 보여줍니다. 첫째, 추적 대상 주원고 11편의 참고문헌 315건 중 추론 로그에서 유지된 문헌은 102건뿐이고 230건(69.28%)이 탈락한 반면, 추론 로그에 없던 문헌 213건(67.62%)이 사후에 새로 채워져 양방향 합집합 545건 대비 자카드 일치도가 18.72%에 불과합니다(#287은 54건 중 49건인 90.7% 탈락). 둘째, #017 추론 로그 1부 전반에서 20회 이상 반복 호출된 자사 동반 원고 [17] (카탈란 상수의 무리성), [18] (결합 딕만 법칙)과 #159의 [46] (단색 유한 합·곱) 등 OpenAI 2026년 자체 동반 프리프린트 3건은 3 / 3 (100%) 전량 제외되어, 원고 간 내부 의존성까지 지워졌습니다.

### Q3 (10개 분야 수학 엔진의 실제 작동 원리): 포장 문제를 걷어냈을 때, 10편의 추론이 난제를 돌파하는 핵심 수학 기전은 무엇인가?
출처 교체와 별개로, 추론 로그 내부의 핵심 수학적 전환점들은 정합적인 대수·조합·해석적 결합을 담고 있습니다.
1. #017 원주율 무리수 지수($\mu(\pi) = 2$): 42쪽 중 39쪽을 할애한 1부는 초기가하 가중치 최적화로 자일베르거-주딜린 상한 7.1032...를 62/25 = 2.48 < 5/2까지 낮춰 플린트-힐스 급수 수렴 조건($2\mu - 5 = -1/25 < 0$)은 먼저 달성하지만, 단일 유리수 Box 장벽($1 + 1/\sqrt{a} > 2$) 때문에 목표인 $\mu(\pi) = 2$에는 도달하지 못합니다. 이어지는 2쪽짜리 2부에서 투도세(Tudose)의 3중 베타 적분 행렬식 $I_r(n,m)$에 $m = 2n$을 대입해 분모 $(n!)^3$을 약분하고 $((3n)!)^2$ 감쇠로 $\mu(\pi) = 2$를 완결합니다.
2. #087 말러 추측 및 #221 희석 스핀 유리: #087은 3차원 하너 정육면체($64/6 = 32/3$)와 일반 단체($256/36 = 64/9$)의 부피곱 격차 $32/9$($36$배 스케일 384 vs 256)를 극체 쌍대성, 리카티 곡률 여유(194 > 180), 32차 유리수 베른슈타인 다항식 인증서로 마감하며, #221은 4차 공동(cavity) 볼록성 차이를 제곱합 $(A-B)^2((A+B)^2 + 2B^2) \ge 0$으로 인수분해합니다.
3. #102 유일 게임, #197 표수 2 카플란스키, #271 하이젠베르크, #287 자유군 인자, #362 블라소프-맥스웰: #102는 희소 사영 척도 $\beta = k^{-2/3}$에서 충돌항 $k\beta^2 = k^{-1/3} \to 0$과 유효 차수 $k\beta = k^{1/3} \to \infty$를 동시에 확보하고, #197은 표수 2 군환에서 린니크 합동 차수와 평면 판 캄펜 오일러 부등식 모순($B + W + F \le E + 3/2 < E + 2$)을 결합하며, #271은 적외선 파수 껍질 비 $4s < 5s$로, #287은 압축 불변량 $t^2(r' - 1) = r - 1$($r=3, t=\sqrt{2} \implies r'=2$)로, #362는 상대론적 특성선 지수 여유분 $496/1000 - 410/1000 = 43/500 > 0$으로 증명을 닫습니다.

### Q4 (3단계 범위 축소 깔때기): 원고 22편에서 추론 로그 10편, 다시 비교 챌린지까지 무엇이 빠져나가는가?
원고, 추론 로그, Lean 4 비교 챌린지 세 계층을 일대일로 대조하면 단계별 축소 깔때기(22 -> 11 -> 9 -> 7)가 확인됩니다.
