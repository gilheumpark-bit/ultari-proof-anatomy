## 2. 자동 검증 게이트 실행 명령 및 통과 기준

1. Lean 4 커널 및 중첩 괄호 가설 변이 전수 사살 (441/441 = 286/286 + 155/155, 미사용·공허 가설 0건 검증):
   ```bash
   lean proofs/qrh_mathematician_referee_audit.lean
   lean proofs/qrh_eight_tasks_critical_upgrade.lean
   ```
   * 통과 기준: 종료 코드 0, 0 sorry, 48개 정리(`thm_01`~`thm_48`)의 관계형·술어형 가설 441건(qrh_mathematician_referee_audit.lean 286건 + qrh_eight_tasks_critical_upgrade.lean 155건, [thm_25](../proofs/qrh_mathematician_referee_audit.lean#L314-L337)의 hF : C.AdmissibleFamily F 포함)을 개별적으로 : True로 치환했을 때 441/441건 전수 컴파일 거부(100% 사살). 이 변이 검사는 정리 내부에 쓰이지 않는 잉여·공허 가설(Dead Premise)이 0건임을 기계적으로 보증하는 산술 결합 무결성 검사이며, 가설 자체의 해석적 비자명성 증명은 제4장 4.2절의 인식론적 경계 표에서 별도로 분리합니다.
2. 기호(SymPy) 도출 + 원본 전체 저장소(3,233개 모듈) DAG 감사 + 수치 텐서(PyTorch) 결정론적 재현:
   ```bash
   python3 proofs/verify_qrh_mathematician_audit.py
   ```
   * 통과 기준: 종료 코드 0, SymPy sp.solve/sp.diff/sp.Poly를 통한 전역 SOS 판별식 `3789*s^2 - 8862*s + 4753 = 0`·전달 기울기 22/25, 48/59·하이브리드 7개 단항식 계수 [750, 295, 190, 108, 3162, 3300, 1056]의 제1원리 기호 도출, 원본 DirichletL 2,927개 + SiegelZeros 306개 모듈(compensated_geometry 미참조 0회, 0 sorry) DAG 감사, PyTorch float64 $2^{24}+1 = 16,777,217$개 복소 경로 거리 상수 격자점 및 $[7, 9973]$ 구간 아이젠슈타인 분해 소수 $611$개 전수(1,222개 3차·6차 가우스 행렬의 유한체 가우스 합 크기 $\sqrt{p}$ 및 라마누잔 비대각 직교 크기 $\frac{1}{p-1}$) 수치 확인, `proofs/symbolic_verification_result.json` 바이트 단위 100% 일치.
