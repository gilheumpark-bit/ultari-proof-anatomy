## 2. 자동 검증 게이트 실행 명령 및 통과 기준

1. Lean 4 커널 및 중첩 괄호 가설 변이 전수 포착 (441/441 = 286/286 + 155/155, 미사용·공허 가설 0건 검증):
   ```bash
   lean proofs/qrh_mathematician_referee_audit.lean
   lean proofs/qrh_eight_tasks_critical_upgrade.lean
   ```
   * 통과 기준: 종료 코드 0, 0 sorry, 48개 정리(`thm_01`~`thm_48`)의 관계형·술어형 가설 441건(qrh_mathematician_referee_audit.lean 286건 + qrh_eight_tasks_critical_upgrade.lean 155건, [thm_25](../proofs/qrh_mathematician_referee_audit.lean#L314-L337)의 hF : C.AdmissibleFamily F 포함)을 개별적으로 : True로 치환했을 때 441/441건 전수 컴파일 거부(100% 포착). 이 변이 검사는 정리 내부에 쓰이지 않는 잉여·공허 가설(Dead Premise)이 0건임을 기계적으로 보증하는 산술 결합 무결성 검사이며, 미해결 해석적 가설($\mathrm{res}_{w_1} = 0$, $\Delta_{\mathrm{hybrid}} = 14/33$, $\mathrm{gain}_{\mathrm{amp}} \ge 2/11$)의 인식론적 상태는 제4장 4.2절에서 별도로 분리합니다.
2. 기호(SymPy) 도출 + 동봉 26개 `oai_ref/` AST/심볼 검증 + 커밋 `4eaee87` 기록 DAG 검증 + 수치 텐서(PyTorch) 결정론적 재현:
   ```bash
   python3 proofs/verify_qrh_mathematician_audit.py
   ```
   * 통과 기준: 종료 코드 0, SymPy `sp.solve`/`sp.diff`/`sp.Poly`로 전역 SOS 판별식 `3789*s^2 - 8862*s + 4753 = 0`·전달 기울기 22/25, 48/59·하이브리드 7개 단항식 계수 `[750, 295, 190, 108, 3162, 3300, 1056]`의 제1원리 기호 도출, 동봉된 26개 `oai_ref/` 모듈 AST/심볼 검증([verify_stage2_referee_critique](../proofs/verify_qrh_mathematician_audit.py#L132-L185): `comp_geom_refs_oai_ref = 0` 및 5개 모듈 베주-지겔 소거 사슬 `0 sorry/axiom`)과 `openai/math` 커밋 `4eaee87`(`PR #70` `ca28f20`) 기준 기록된 원본 DAG 수치(`2,927 DirichletL + 306 SiegelZeros = 3,233`개 디렉터리 파일, `2,924 + 201 = 3,125`개 추이적 DAG 모듈, 하위 2,925개 `DirichletL` 모듈 내 `compensated_geometry` 참조 `0`건; 단, `DirichletL/ElevenTwelfths/Nonvanishing.lean`과 `ZeroDetector.lean`은 `4eaee87` 원본 파일이며 동봉 26개 `oai_ref/`에는 미포함) 검증, PyTorch float64 $2^{24}+1 = 16,777,217$개 복소 경로 거리 상수 격자점([verify_qrh_mathematician_audit.py:279-286](../proofs/verify_qrh_mathematician_audit.py#L279-L286)) 및 $[7, 9973]$ 구간 아이젠슈타인 분해 소수 $611$개 전수(1,222개 3차·6차 가우스 행렬의 유한체 가우스 합 크기 $\sqrt{p}$ 및 라마누잔 비대각 직교 크기 $\frac{1}{p-1}$, [verify_qrh_mathematician_audit.py:228-239](../proofs/verify_qrh_mathematician_audit.py#L228-L239)) 수치 확인, `proofs/symbolic_verification_result.json` 바이트 단위 100% 일치.
