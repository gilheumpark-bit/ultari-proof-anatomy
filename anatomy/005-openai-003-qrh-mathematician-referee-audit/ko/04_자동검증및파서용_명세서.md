## 2. 자동 검증 게이트 실행 명령 및 통과 기준

1. **Lean 4 커널 및 중첩 괄호 가설 변이 전수 사살 (`407/407` = `284/284` + `123/123`)**:
   ```bash
   ~/.elan/bin/lean proofs/qrh_mathematician_referee_audit.lean
   ~/.elan/bin/lean proofs/qrh_eight_tasks_critical_upgrade.lean
   ```
   * 통과 기준: 종료 코드 `0`, `0 sorry`, `46`개 정리(`thm_01`~`thm_46`)의 관계형 가설 `406`건을 개별적으로 `: True`로 치환했을 때 `407/407`건 전수 컴파일 거부(`100%` 사살).
2. **기호(SymPy) + Blackwell GPU(PyTorch) 결정론적 재현**:
   ```bash
   python3 proofs/verify_qrh_mathematician_audit.py
   ```
   * 통과 기준: 종료 코드 `0`, Blackwell GPU `float64` $2^{24}+1 = 16,777,217$개 복소 경로 격자점 및 $[7, 9973]$ 구간 아이젠슈타인 분해 소수 $611$개 전수(`1,222`개 3차·6차 가우스 그램 행렬) 검증 통과, `proofs/symbolic_verification_result.json` 바이트 단위 100% 일치.
3. **핵심 산출물 SHA-256 체크섬 무결성 대조**:
   ```bash
   sha256sum proofs/qrh_mathematician_referee_audit.lean \
             proofs/qrh_eight_tasks_critical_upgrade.lean \
             proofs/verify_qrh_mathematician_audit.py \
             proofs/symbolic_verification_result.json \
             proofs/problem_spec.md
   ```
   * 통과 기준: `5`종 핵심 산출물의 SHA-256 체크섬 100% 일치 (`EXIT 0`).
