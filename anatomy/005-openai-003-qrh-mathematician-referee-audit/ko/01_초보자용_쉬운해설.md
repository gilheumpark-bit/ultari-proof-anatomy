# 1단계: 초보자용 쉬운 해설: 수론 학자와 심사위원이 OpenAI #003에서 확인하는 5가지 질문

Lean 4 파일이 문법 오류 없이 컴파일된다는 것만으로는 충분하지 않습니다. 해석적 수론 학자나 학술지 심사위원이 OpenAI #003($\beta = 7/8$ 준리만 가설 및 지겔 영점 배제)을 심사할 때는 다섯 가지 근본 질문을 던집니다. OpenAI #003 원문 자체는 $\beta = 7/8$까지만 주장하고 증명했으며(0 sorry), 본 감사의 정리 27부터 정리 48은 분모 소거 유리수 지수 전달 관계와 미해결 해석적 가설(특히 $\mathrm{res}_{w_1} = 0$과 $\mathrm{gain}_{\mathrm{amp}} \ge 2/11$)을 전제로 한 $\beta = 1/2$ 조건부 설계도를 형식화한 것입니다.



## 1. 질문 1: 출처 없는 상수(매직 넘버)들은 어디서 나왔는가?

[DirichletL/Parameters.lean:12-17](../proofs/oai_ref/Parameters.lean#L12-L17)을 열면 아무 설명 없이 세 분수 $\alpha_X = 17/48$, $\alpha_Y = 23/48$, $\ell = 1/6$이 등장합니다.
증명을 역추적하면 이 세 값은 세 가지 조건을 동시에 만족하는 $3 \times 3$ 연립방정식의 유일한 해입니다([thm_01_magic_exponents_unique_3x3_system](../proofs/qrh_mathematician_referee_audit.lean#L16-L26)):
1. 적분 경로 고정 ($\ell = 1/6 = 8/48$): 주 멜린 적분 경로를 $\mathrm{Re}(z) = 1/6$에 둡니다.
2. 제곱수 인자 이동 ($\alpha_X - \ell = 3/16 = 9/48$): 이 조건에서 $\alpha_X = 8/48 + 9/48 = 17/48$이 결정됩니다.
3. 삼차 가우스 합 $L^2$-이득 ($(5\alpha_X + \alpha_Y)/12 = 3/16$): 이 조건에서 $\alpha_Y = 23/48$이 결정됩니다.

마찬가지로 지겔 영점 모듈([SiegelZeros/Estimates/GeometricBoundary.lean:26](../proofs/oai_ref/GeometricBoundary.lean#L26), [SiegelZeros/Selection/PivotBounds.lean:63-65](../proofs/oai_ref/PivotBounds.lean#L63-L65))의 상수 $H = 86,713,344$와 $N_0 = 18,818$은 가우스 기호 상한 $\lfloor 96t \rfloor + 1 \le 97t$에서 나옵니다([thm_21_siegel_zero_magic_constants_86713344_and_18818](../proofs/qrh_mathematician_referee_audit.lean#L257-L265)). 공통 인수 $97^2 = 9,409$로부터 $N_0 = 2 \times 97^2 = 18,818$과 $H = 12 \times 192 \times 37,636 = 86,713,344$가 도출됩니다.



## 2. 질문 2: 전술적 형식화 여유분(formalization slack)과 미참조 정리는 어떻게 구분되는가?

1. 3단계 비예외 꼬리항 형식화 여유분 (181/3264, 215/3264, 487/3264):
   - [DirichletL/Detector/LowSourceScales.lean:88-98](../proofs/oai_ref/LowSourceScales.lean#L88-L98)은 nlinarith 증명 마감 편의를 위해 상수 $B$를 $Z^{1/16}$으로 완화하여 지수 $1/32 = 102/3264$의 형식화 여유분(formalization slack)을 둡니다.
   - [DirichletL/Detector/GramScaleLoss.lean:29](../proofs/oai_ref/GramScaleLoss.lean#L29)는 $P^{-\delta}$ 감쇠 인자를 완화해 $\delta_{\mathrm{SOS}} = 79/204$에서 $79/3264$의 여유분을 더합니다.
   - 여기에 $1/96$ 묶음 여유분을 더하면 3항 합계 $215/3264 \approx 0.0659$([thm_04_gram_relaxation_three_tier_exponent_losses](../proofs/qrh_mathematician_referee_audit.lean#L53-L64))가 되고, 약수 상한 $1/12$까지 합치면 $487/3264 \approx 0.1492$가 됩니다.
2. 약분 전 삼각부등식 적용 (Q >= 480 대 Q >= 128):
   - [DirichletL/Detector/Local.lean:16-24](../proofs/oai_ref/Local.lean#L16-L24)에서 분모 인자 $(1-V)$는 다항식으로 정확히 약분됩니다([thm_07_marked_factor_one_minus_V_polynomial_cancellation](../proofs/qrh_mathematician_referee_audit.lean#L96-L106)).
   - 그러나 [DirichletL/Detector/CorrectionBounds.lean:26, 58](../proofs/oai_ref/CorrectionBounds.lean#L26)이 약분 전에 삼각부등식을 먼저 적용하므로 소수 노름 임계치가 $Q \ge 128$에서 $Q \ge 480$으로 이동하며 30개 소 아이디얼 노름만큼의 형식화 여유분이 생깁니다([thm_08_correction_bounds_unreduced_480_vs_reduced_128](../proofs/qrh_mathematician_referee_audit.lean#L107-L119)).
3. Parameters.lean의 미참조 정리 차이(hygiene delta):
   - 위 검출기 모듈의 활성 형식화 여유분과 별개로, [DirichletL/Parameters.lean:12-17](../proofs/oai_ref/Parameters.lean#L12-L17)에 있는 compensated_geometry와 보조정리 3개는 동봉된 26개 참조 모듈과 openai/math 커밋 4eaee87 기준 기록된 2,925개 하위 DirichletL 모듈에서 외부 참조가 0건인 미참조 정리입니다([thm_05_dead_constraint_parameters_vs_active_poisson](../proofs/qrh_mathematician_referee_audit.lean#L65-L77)).
4. 4단계 베주-지겔 가설 소거 사슬:
   - [SiegelZeros/Estimates/GeometricBoundary.lean:18-22](../proofs/oai_ref/GeometricBoundary.lean#L18-L22)의 hgeometry 가설은 [SiegelZeros/Intersection/IsolatedBezoutFromRegularSelection.lean:346-366](../proofs/oai_ref/IsolatedBezoutFromRegularSelection.lean#L346-L366), [SiegelZeros/Structure/ArithmeticCutoffTransport.lean:488-515](../proofs/oai_ref/ArithmeticCutoffTransport.lean#L488-L515), [SiegelZeros/Intersection/BezoutBoundary.lean:13-20](../proofs/oai_ref/BezoutBoundary.lean#L13-L20), [SiegelZeros/Conclusions/Theorem.lean:11-20](../proofs/oai_ref/Theorem.lean#L11-L20)을 거쳐 무조건부로 소거됩니다([thm_23_siegel_zero_conditional_hgeometry_vs_cubic_independence](../proofs/qrh_mathematician_referee_audit.lean#L278-L287)).



## 3. 질문 3·4: 왜 $\beta = 7/8$에서 멈췄으며, 경계 사례는 어떻게 처리했는가?

1. 이중 적분 경로 분리: $w = 1$ 유수에서 $\mathrm{Re}(z) = 1/6$을 유지하면 극점을 침범하므로, 경로를 $\mathrm{Re}(z) = 33/200 < 1/6$으로 왼쪽 이동해 $29/1200 > 0$의 안전 간격을 확보합니다([thm_14_double_contour_w_and_z_residue_separation_budget](../proofs/qrh_mathematician_referee_audit.lean#L178-L189)).
2. $7/8$ 아래로 낮추기 위한 그람 이득: $\beta = 5/6, 3/4, 69/100$에 도달하려면 비대각 가우스 그람 이득이 각각 $\Delta_{\mathrm{gram}} = 1/16, 3/16, 111/400$만큼 필요합니다([thm_16_bilinear_gram_cancellation_thresholds_5_6_and_3_4](../proofs/qrh_mathematician_referee_audit.lean#L199-L209)).
3. 나쁜 소수 $Q = 3, 4$ 배제: badPrimeMask로 $p \mid 6$을 걸러내면 모든 소수 거듭제곱 $Q \ge 7$은 $Q \equiv 1 \pmod 6$을 만족합니다([thm_19_eisenstein_sextic_symbol_requires_Q_ge_7_mod_6_eq_1](../proofs/qrh_mathematician_referee_audit.lean#L236-L245)).
4. 이차 지표 대 삼차 지표: 지겔 영점은 실 이차 지표에서만 발생하며, 복소수 삼차 지표에는 지겔 영점이 존재하지 않습니다([thm_22_biquadratic_klein4_torus_jet_exponent_gap](../proofs/qrh_mathematician_referee_audit.lean#L268-L277)).



## 4. 질문 5: $\beta = 1/2$ 임계선으로 가는 조건부 전달 설계도

원문 #003은 $\beta = 7/8$까지만 증명했으며(0 sorry), 정리 27부터 정리 48은 무조건부 대수적 지수 전달과 미해결 해석적 가설(특히 $\mathrm{res}_{w_1} = 0$과 $\mathrm{gain}_{\mathrm{amp}} \ge 2/11$)을 전제로 한 $\beta = 1/2$ 조건부 전달 경로를 다음과 같이 분리해 형식화합니다.

1. 전역 SOS 안장점 ($\beta_{\mathrm{SOS}}(0) = \frac{6843 - 7\sqrt{921}}{7578} \approx 0.874975$): 전체 구간 $(\delta, y) \in [0, 5/6] \times [0, 1/2]$에서 성립하는 무조건부 전역 상한이며, 유리수 증인 $\frac{41999}{48000} < \frac{7}{8}$에서 확인됩니다([thm_32](../proofs/qrh_mathematician_referee_audit.lean#L412-L430), [thm_33](../proofs/qrh_mathematician_referee_audit.lean#L431-L441)).

2. 국소 $\delta = 0$ 단면 균형점 ($\frac{131}{150} \approx 0.8733$ 및 $\frac{209}{240} \approx 0.8708$): [DirichletL/Detector/CentralExponent.lean:15-81](../proofs/oai_ref/CentralExponent.lean#L15-L81)과 [DirichletL/Detector/GramBound.lean:56](../proofs/oai_ref/GramBound.lean#L56)에서 얻어지는 국소 경계 균형점입니다([thm_27](../proofs/qrh_mathematician_referee_audit.lean#L356-L367), [thm_28](../proofs/qrh_mathematician_referee_audit.lean#L368-L378), [thm_34](../proofs/qrh_mathematician_referee_audit.lean#L444-L451)).

3. 비예외 꼬리항 바닥 ($\beta_{\mathrm{floor}} = \frac{4103}{4896} \approx 0.8380$, 묶음 포함 시 $\frac{4069}{4896}$): 영모드 제거 및 [thm_04](../proofs/qrh_mathematician_referee_audit.lean#L53-L64)의 형식화 여유분 복원 후 분리된 비예외 꼬리항의 바닥 지수입니다.

4. coordR 슈티켈베르거 극점 이동 ($\frac{2}{3} \to \frac{7}{12} \to \frac{1}{2}$): [DirichletL/Detector/EulerCoordinates.lean:36](../proofs/oai_ref/EulerCoordinates.lean#L36)에서 $\psi_{\mathrm{Stick}}\eta^6$($k_\infty = -6 \neq 0$)를 인수분해해 $2/3$ 오일러 곱 수렴 장벽을 낮춥니다([thm_29](../proofs/qrh_mathematician_referee_audit.lean#L379-L385), [thm_30](../proofs/qrh_mathematician_referee_audit.lean#L388-L399)).

5. HighRows 대칭 코시 상자 ($[0.48, 0.52]$ 개방): [DirichletL/Detector/HighRowsCentralTerms.lean:38-114](../proofs/oai_ref/HighRowsCentralTerms.lean#L38-L114)에서 $z_{\mathrm{high}} = 7/20$ 이동으로 9개 분기를 $0.48 < 1/2$까지 개방합니다([thm_31](../proofs/qrh_mathematician_referee_audit.lean#L400-L411), [thm_42](../proofs/qrh_eight_tasks_critical_upgrade.lean#L77-L96)).

6. $\beta = 1/2$ 조건부 하이브리드 임계치 ($\Delta_{\mathrm{hybrid}} = \frac{14}{33}$): 결합 경로 $(35/66, 59/66, 7/11, 7/20)$에서 $\beta = 1/2$ 도달에 필요한 조건부 비대각 상쇄 이득을 역산한 값입니다([thm_35](../proofs/qrh_mathematician_referee_audit.lean#L454-L461)부터 [thm_38](../proofs/qrh_mathematician_referee_audit.lean#L486-L498)).

7. 매개변수 격상 명세 및 조건부 단일 $\zeta(s)$ 교량 ($\mathrm{gain}_{\mathrm{amp}} \ge \frac{2}{11}$): 1단계는 5개 모듈군의 분모 소거 매개변수 격상 명세를 형식화하고([thm_39](../proofs/qrh_eight_tasks_critical_upgrade.lean#L21-L37)부터 [thm_43](../proofs/qrh_eight_tasks_critical_upgrade.lean#L97-L121)), 2단계는 미해결 해석적 가설($\mathrm{res}_{w_1} = 0$, $\mathrm{gain}_{\mathrm{amp}} \ge \frac{2}{11}$)을 전제로 한 조건부 보로노이 전달과 단일 $\zeta(s)$ 교량 임계치를 역산합니다([thm_44](../proofs/qrh_eight_tasks_critical_upgrade.lean#L122-L140)부터 [thm_48](../proofs/qrh_eight_tasks_critical_upgrade.lean#L200-L241)).
