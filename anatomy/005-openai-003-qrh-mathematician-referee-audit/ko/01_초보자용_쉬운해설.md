# 01. 초보자용 쉬운 해설: 수학자와 심사위원은 이 논문에서 무엇을 보려 하는가?

컴퓨터가 "이 코드는 문법 오류가 없습니다"라고 도장을 찍어 주는 것과, 수학자가 "이 논문이 어떻게 난제를 풀었으며 어디가 진짜 핵심이고 어디가 거품인가"를 이해하는 것은 전혀 다른 일입니다. 이 문서는 수학 전공자가 아니더라도 **수론학자와 저널 심사위원이 OpenAI `#003`(리만 가설 연구)을 해부할 때 던지는 핵심 질문과 $\beta = 7/8 \to 0.8311 \to 1/2$ 돌파 경로**를 한눈에 이해할 수 있도록 설명합니다.

## 1. 첫 번째 질문: "가장 중요한 마법의 숫자들은 도대체 어디서 튀어나왔는가?" (핵심 트릭 추출)

OpenAI `#003`의 Lean 4 코드([`Parameters.lean:12-17`](../proofs/oai_ref/Parameters.lean#L12-L17))를 열면 아무런 설명 없이 분수 세 개가 등장합니다.
* $\alpha_X = 17/48$, $\alpha_Y = 23/48$, $\ell = 1/6$

코드만 봐서는 왜 하필 분모가 $48$이고 분자가 $17, 23$인지 알 수 없습니다. 하지만 수학자의 눈으로 뒤에서부터 역추적해 보면, 이 세 숫자는 **세 가지 물리적·수론적 조건이 정확히 한 점에서 만나는 $3 \times 3$ 연립방정식의 유일한 해**([`thm_01_magic_exponents_unique_3x3_system`](../proofs/qrh_mathematician_referee_audit.lean#L16-L23))입니다.

1. **적분 경로 고정 ($\ell = 1/6 = 8/48$)**: 복소평면에서 오차항을 자르는 기준선을 $z = 1/6$에 세웁니다.
2. **예외적인 소수(제곱인자) 방어 ($\alpha_X - \ell = 3/16 = 9/48$)**: 까다로운 제곱인자 부분에서도 손해를 보지 않으려면 $\alpha_X = 8/48 + 9/48 = 17/48$이어야 합니다.
3. **3차 가우스 합 파동 상쇄 ($(5\alpha_X + \alpha_Y)/12 = 3/16$)**: 3차 가우스 합이 만들어내는 $P^{1/6}$ 파동 절약량이 정확히 목표치 $3/16$이 되려면 $5(17/48) + \alpha_Y = 108/48$, 즉 $\alpha_Y = 23/48$이어야 합니다.

마찬가지로 지겔 영점(Siegel Zero) 배제 모듈([`GeometricBoundary.lean:26`](../proofs/oai_ref/GeometricBoundary.lean#L26))에 등장하는 거대한 정수 **$H = 86,713,344$** 와 **$N_0 = 18,818$** 도 하늘에서 떨어진 숫자가 아닙니다([`thm_21_siegel_zero_magic_constants_86713344_and_18818`](../proofs/qrh_mathematician_referee_audit.lean#L257-L265)).
* 바닥함수 부등식 $\lfloor 96t \rfloor + 1 \le 97t$($97 = 96 + 1$)에서 차원 비교 상수 $N_0 = 2 \times 97^2 = 18,818$(`twice_pivot_floor_square_le`)과 $M^2/(4Q)$ 하한 분모 $1/c_1 = 4 \times 97^2 = 37,636$이 각각 도출되어 공통 인자 $97^2 = 9,409$를 공유합니다([`PivotBounds.lean:63-65`](../proofs/oai_ref/PivotBounds.lean#L63-L65)).
* 피벗 합 상한 상수 $C_1 = 2 \times 96 = 192$와의 비율 $C_1 / c_1 = 192 \times 37,636 = 7,226,112$를 정확히 $1/12$ 이하로 눌러 주기 위해 $12$를 곱한 값이 바로 $H = 12 \times 7,226,112 = 86,713,344$입니다.

## 2. 두 번째 질문: "AI가 코딩 편의를 위해 버린 여유분과 모듈 연결 구조는 어떠한가?" (심사위원의 비판)

### ② 약분하기 전에 절댓값부터 씌운 실수 (`[중-2]`)
분수 $\frac{(1-V) \times (\text{다항식})}{1-V}$을 계산할 때, 분모와 분자의 $(1-V)$를 먼저 약분하면 식이 훨씬 간단해집니다([`thm_07_marked_factor_one_minus_V_polynomial_cancellation`](../proofs/qrh_mathematician_referee_audit.lean#L96-L103)). 그런데 [`CorrectionBounds.lean:26, 58`](../proofs/oai_ref/CorrectionBounds.lean#L26)은 약분을 하지 않고 먼저 $\left|\frac{1}{1-V}\right| \le 2$라는 부등식을 씌운 뒤 나중에 $|1-V| \le 2$를 또 곱해서 오차 계수를 $c_{\mathrm{red}} = 2(4+28) = 64$에서 $c_{\mathrm{raw}} = 2(4+2\cdot 56) = 232 \le 240$으로 3.6배 이상 부풀렸습니다. 그 결과 $Q \ge 128$(기하급수 $Q \ge 129$, $[7, 128)$ 구간 비분기 $\mathbb{Z}[\omega]$ 소 아이디얼 노름 $16$개·소 아이디얼 $30$개)면 될 조건이 $Q \ge 480$(비분기 노름 $46$개·소 아이디얼 $89$개)으로 늘어났고, 약분만 먼저 해도 $46 - 16 = 30$개의 소 아이디얼 노름(소 아이디얼 $89 - 30 = 59$개)이 즉시 절약됩니다([`thm_08_correction_bounds_unreduced_480_vs_reduced_128`](../proofs/qrh_mathematician_referee_audit.lean#L107-L116)).

### ③ 지겔 영점 모듈의 4단계 베주(Bézout) 가설 소거 사슬 (`[구조 감사]`)
[`GeometricBoundary.lean:18-22`](../proofs/oai_ref/GeometricBoundary.lean#L18-L22) 파일 하나만 떼어 놓고 보면 `hgeometry : ActualCutoffSpanning`을 가설 인자로 입력받는 조건부 정리처럼 보입니다. 그러나 발췌본 5개 파일 및 원본 `SiegelZeros` 모듈 전체(`201`개 추이적 의존 모듈, `0 sorry`, `0 axiom`)의 연결 고리를 추적하면, [`IsolatedBezoutFromRegularSelection.lean:346-366`](../proofs/oai_ref/IsolatedBezoutFromRegularSelection.lean#L346-L366) $\to$ [`ArithmeticCutoffTransport.lean:488-515`](../proofs/oai_ref/ArithmeticCutoffTransport.lean#L488-L515) $\to$ [`BezoutBoundary.lean:13-20`](../proofs/oai_ref/BezoutBoundary.lean#L13-L20) $\to$ [`Theorem.lean:11-20`](../proofs/oai_ref/Theorem.lean#L11-L20)의 4단계를 거쳐 이 가설이 소거되는 구조를 확인할 수 있으며, 본 패키지의 [`thm_25`](../proofs/qrh_mathematician_referee_audit.lean#L314-L323)는 그 추상 명제 사슬(`P → Q → R → S → T`)을 모형화합니다([`thm_23_siegel_zero_conditional_hgeometry_vs_cubic_independence`](../proofs/qrh_mathematician_referee_audit.lean#L278-L284)).
