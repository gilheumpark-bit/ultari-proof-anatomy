## 1. 마법 상수 및 $\beta \to 1/2$ 전달 방정식의 대수적 역공학

### 1.1 탐침 스케일 $(\alpha_X, \alpha_Y, \ell) = (17/48, 23/48, 1/6)$의 $3 \times 3$ 연립방정식 ([`thm_01`](proofs/qrh_mathematician_referee_audit.lean#L16-L23), [`thm_02`](proofs/qrh_mathematician_referee_audit.lean#L27-L36))

$X = Z^{\alpha_X}$, $Y = Z^{\alpha_Y}$, $L = Z^{\ell}$에 대해 [`Parameters.lean:12-17`](proofs/oai_ref/Parameters.lean#L12-L17)과 [`LowSourceScales.lean:20-98`](proofs/oai_ref/LowSourceScales.lean#L20-L98)의 세 경계 조건을 연립하면 다음과 같습니다.

$$\begin{cases}
\ell = \dfrac{1}{6} = \dfrac{8}{48} & (\text{멜린 주 적분선 } z_{\mathrm{re}} = 1/6 \text{ 고정}) \\[6pt]
\alpha_X - \ell = \dfrac{3}{16} = \dfrac{9}{48} & (\text{제곱인자 예외 그램 이동 한계}) \\[6pt]
\dfrac{5\alpha_X + \alpha_Y}{12} = \dfrac{3}{16} \iff 5\alpha_X + \alpha_Y = \dfrac{108}{48} & (\text{3차 가우스 합 } P^{1/6}\text{의 } L^2\text{-절약량})
\end{cases}$$

위 세 식으로부터 $\alpha_X = 8/48 + 9/48 = 17/48$, $\alpha_Y = 108/48 - 85/48 = 23/48$이 유일하게 결정됩니다. [`LowSourceScales.lean:88-98`](proofs/oai_ref/LowSourceScales.lean#L88-L98)의 `hB : B ≤ Z^(1/16)` 인플레이션을 제거하고 $2\alpha_X - \alpha_Y = \ell = 1/6$을 직접 풀면 $7\alpha_X = 203/84 \implies (\alpha_X, \alpha_Y) = (29/84, 11/21)$이 됩니다([`thm_02_constant_B_absorption_inflation_and_uninflated_scales`](proofs/qrh_mathematician_referee_audit.lean#L27-L36)).

### 1.2 무리수 안장점 $\delta^*$ 대 유리수 SOS 고정점 $\delta_{\mathrm{SOS}} = 79/204$ ([`thm_06`](proofs/qrh_mathematician_referee_audit.lean#L78-L87))

[`Endpoint.lean:29-31`](proofs/oai_ref/Endpoint.lean#L29-L31)의 `balancedExponent δ y`를 경계 $y = 0$에서 $\delta$에 대해 미분하면 분자 다항식은 다음 2차식이 됩니다.
$$P(\delta) = 9384\delta^2 - 25160\delta + 8325, \qquad \Delta = 25160^2 - 4(9384)(8325) = 320,538,400 = 140^2 \times 16354$$
참 안장점은 무리수 $\delta^* = \frac{185}{138} - \frac{35\sqrt{16354}}{4692} \approx 0.38663756$이지만, [`Endpoint.lean:58-62`](proofs/oai_ref/Endpoint.lean#L58-L62)는 $(204\delta - 79)^2$을 없애기 위해 $\delta_{\mathrm{SOS}} = 79/204 \approx 0.3872549$를 고정점으로 잡았습니다($204^2 P(79/204) = -459,816 < 0$).

### 1.3 임계선($\delta = 0$) 균형점, 20개 모듈 전역 SOS 안장점 및 [길 A + 길 B] 하이브리드 결합 방정식 ([`thm_27`](proofs/qrh_mathematician_referee_audit.lean#L356-L364)~[`thm_38`](proofs/qrh_mathematician_referee_audit.lean#L486-L497))

[`PrincipalRemainderBounds.lean:520-522`](proofs/oai_ref/PrincipalRemainderBounds.lean#L520-L522)의 주항 이중 유수 지수 $E_{\mathrm{signal}}(\beta, \alpha_X) = \beta - \frac{29}{36} + \frac{\alpha_X}{3}$와 [`LowGramScale.lean:38-45`](proofs/oai_ref/LowGramScale.lean#L38-L45)의 3차 가우스 주항 지수 $E_{\mathrm{Low}}(\alpha_X, \alpha_Y, \Delta_{\mathrm{gram}}) = \frac{5\alpha_X + \alpha_Y}{12} - \Delta_{\mathrm{gram}}$을 일치시키면 2변수 영점 부재 지수 법칙은 다음과 같습니다.
$$\beta_{\mathrm{Low}}(\alpha_X, \alpha_Y, \Delta_{\mathrm{gram}}) = \frac{29}{36} + \frac{\alpha_X + \alpha_Y}{12} - \Delta_{\mathrm{gram}}$$
1. **임계선($\delta = 0$) 국소 균형점**: 무팽창 푸아송 꼬리 직선 $\alpha_Y = 2\alpha_X - 1/6$([`LowGramScale.lean:15`](proofs/oai_ref/LowGramScale.lean#L15)) 위에서 $\beta(\alpha_X, \Delta_{\mathrm{gram}}) = \frac{19}{24} + \frac{\alpha_X}{4} - \Delta_{\mathrm{gram}}$이며, $\delta = 0$ 고차 행 균형 조건 $\alpha_Y - \alpha_X = 4/25$와 연립하면 $(\alpha_X^*, \alpha_Y^*, d_0^*) = (49/150, 73/150, 21/25)$($z_{\mathrm{high}}'=7/20$에서는 $(19/60, 7/15, 17/20)$), $\beta(\Delta_{\mathrm{gram}}) = 131/150 - \Delta_{\mathrm{gram}}$($z_{\mathrm{high}}'=7/20$에서는 $209/240 - \Delta_{\mathrm{gram}}$)이 도출됩니다.
2. **20개 모듈 전역 $(\delta, y) \in [0, 5/6] \times [0, 1/2]$ SOS 안장점 및 임계선($\beta = 1/2$) 3중점 ([`thm_33`](proofs/qrh_mathematician_referee_audit.lean#L431-L441))**: 모든 고차 행 빈 $(\delta, y) \in [0, 5/6] \times [0, 1/2]$ 전 구간에서 $4 A_M C_M - B_M^2 \ge 0$이 성립하려면 $s = \alpha_X + \alpha_Y$가 $3789 s^2 - 8862 s + 4753 \le 0$을 만족해야 하므로, $\Delta_{\mathrm{gram}} = 0$에서 전역 SOS 최소 지수는 $\beta_{\mathrm{SOS}}(0) = \frac{6843 - 7\sqrt{921}}{7578} \approx 0.87497547 < \frac{7}{8}$(유리수 증인 $(71/200, 5737/12000)$에서 $\beta_{\mathrm{SOS}}(0) = \frac{41999}{48000} < \frac{7}{8}$, [`Parameters.lean:13`](proofs/oai_ref/Parameters.lean#L13)의 $s \ge 5/6$ 부과 시 정확히 $\frac{7}{8}$)입니다. 또한 $\Delta_{\mathrm{gram}} > 0$에서 $(\alpha_X(u), \alpha_Y(u)) = (17/48 + u, 23/48 + 2u)$를 따라 전역 SOS 전달 법칙 **$\beta_{\mathrm{SOS}}^*(\Delta_{\mathrm{gram}}) = \frac{7}{8} - \frac{22}{25}\Delta_{\mathrm{gram}}$**([`Parameters.lean:16`](proofs/oai_ref/Parameters.lean#L16) 튜플 장벽 포함 시 **$\beta_{\mathrm{full}}^{**}(\Delta_{\mathrm{gram}}) = \frac{7}{8} - \frac{48}{59}\Delta_{\mathrm{gram}}$**)이 성립하며, 임계선 $\beta = 1/2$에서 유일한 3중점은 **$(\alpha_X^{**}, \alpha_Y^{**}, d_0^{**}) = (\frac{2}{3}, \frac{7}{6}, \frac{1}{2})$**([`CentralExponent.lean:76`](proofs/oai_ref/CentralExponent.lean#L76)의 `hd : d ≤ 1/2`와 정확히 일치, $\max_{\delta, y} \beta_{\mathrm{High}} = \frac{1}{4} < \frac{1}{2}$, $\Delta_{\mathrm{gram}}(1/2) = \frac{11}{24}$)입니다.
3. **[길 A]·[길 B] 단독 진행의 막다른 길(No-Go), [길 A + 길 B] 하이브리드 결합 임계점 및 2대 해석 과제 해부 ([`thm_34`](proofs/qrh_mathematician_referee_audit.lean#L444-L451)~[`thm_38`](proofs/qrh_mathematician_referee_audit.lean#L486-L497))**: 길 A 단독 진행 시 $E_{\mathrm{Low}}^{\mathrm{eff}} = E_{\mathrm{High}}(0) = 0$ 영에너지 천장은 $(\alpha_X, \alpha_Y) = (4/9, 13/18)$($\Delta_{\max} = 53/216$)에서 **$\beta_{\min}^{\mathrm{A}} = 71/108 \approx 0.6574 > 1/2$** 에 막히고, 길 B 단독 진행 시 $d_0 = 7/6 - \alpha_X$에서 $\partial E_{\mathrm{High}}/\partial z_{\mathrm{high}} = 0$이므로 저차 행이 움직이지 않습니다. 반면 길 A의 동적 척도 결합선($11\alpha_X + 7\alpha_Y = 7 + 12\Delta_{\mathrm{hybrid}}, 2\alpha_X - \alpha_Y = 1/6, d_0 = 7/6 - \alpha_X \implies \beta = 131/150 - \frac{22}{25}\Delta_{\mathrm{hybrid}}$)과 길 B의 $w.\mathrm{re} = 1 - a$ 쌍대 경로 감쇠($\frac{1}{2}\alpha_Y$, [`CentralExponent.lean:95`](proofs/oai_ref/CentralExponent.lean#L95)) 및 $z_{\mathrm{high}}' = 7/20$을 결합하면, $\beta = 1/2$($\Delta_{\mathrm{hybrid}} = 14/33 = 56/132$)에서 **$(\alpha_X^{**}, \alpha_Y^{**}, d_0^{**}, z_{\mathrm{high}}') = (\frac{35}{66}, \frac{59}{66}, \frac{7}{11}, \frac{7}{20})$** 이 되며, 하이브리드 에너지 용량 **$\frac{39}{132} + \frac{59}{132} = \frac{98}{132} > \frac{56}{132}$**(여유분 $\frac{42}{132} = \frac{7}{22} > 0$), $k=2$ 슈바르츠 푸아송 꼬리 마진 $4/11 = 48/132 > 0$, 순수 쌍대 감쇠 역전 마진 $+3/132 = +1/44 > 0$, 보편 멜린 스케일 항등식(`Δx = 0`, $z$-유수 절약 $-1/16500 < 0$, 쌍대 $w=1/2$ 절약 $-167/375 < 0$), 이중 슈티켈베르거 오일러 인수분해($e_{\min} = 144/100 > 1$), 내부 SOS 안장 소멸(단항식 계수 $(750, 295, 190, 108, 3162, 3300, 1056) > 0$), 그리고 슈티켈베르거 수직 모멘트 차수 $(8, 5) \to (11, 8)$이 동시에 달성됩니다.

4. **잔여 8대 과제 완결(원본 `oai_ref` 5대 모듈 격상 `thm_39`~`thm_43` + 순수 해석 보조정리 및 단일 $\zeta(s)$ 가교 `thm_44`~`thm_46`, [`qrh_eight_tasks_critical_upgrade.lean`](proofs/qrh_eight_tasks_critical_upgrade.lean#L21-L171))**: 1단계로 `Parameters.lean`·`LowSourceScales.lean`($k=2$ 꼬리 절약 $4/11$, 상수 흡수 용량 $1/16 \to 2/11$, 배율 $32/11$, [`thm_39`](proofs/qrh_eight_tasks_critical_upgrade.lean#L21-L31)), `Local.lean`·`CorrectionBounds.lean`($Q_{\min}: 480 \to 112$, $e_{\min}=144/100 > 1$, 꼬리 감쇠 $11/25$, [`thm_40`](proofs/qrh_eight_tasks_critical_upgrade.lean#L38-L51)), `PrincipalRemainderBounds.lean`($(11,8)$ 모멘트 및 $e=1/1000$에서 $-1/16500, -1421/33000, -14696/33000 < 0$ 절약, [`thm_41`](proofs/qrh_eight_tasks_critical_upgrade.lean#L58-L70)), `HighRowsCentralTerms.lean`·`ParametersHighData.lean`($a_{\min} = 12/25 < 1/2$ 및 4대 예산 $1/48, 17/800, 2/33000, 3/200 > 0$, [`thm_42`](proofs/qrh_eight_tasks_critical_upgrade.lean#L77-L90)), `CentralExponent.lean`·`Endpoint.lean`·`Theorem.lean`(`b_den` $\in [70/108, 215/108]$, 7개 단항식 합 $8861$, 저차 감쇠 마진 $+1/44$, [`thm_43`](proofs/qrh_eight_tasks_critical_upgrade.lean#L97-L109))을 증명하고, 2단계로 `LowRows` 보로노이-멜린 도체 중립 전달($\Delta e_{\mathrm{cond},w} = 0 < \Delta e_{\mathrm{cond},x} = 35/66$, [`thm_44`](proofs/qrh_eight_tasks_critical_upgrade.lean#L122-L134)), $k_\infty = -6$ 그뢰센하락터 정칙성 및 $d_K=2$ 볼록성($\mu_{\mathrm{bi}} = 102/100 \le 3$, [`thm_45`](proofs/qrh_eight_tasks_critical_upgrade.lean#L141-L149)), 그리고 지표 가족($M_{\mathrm{fam}} = Q/Y$)에서 단일 $\zeta(s)$($M_{\mathrm{single}}=1$)로의 계수-1 대각 붕괴 결손 $\Delta_{\mathrm{collapse}} = 2/11 = 24/132$($\lambda_{\mathrm{crit}} = 4/11$) 및 증폭·부분볼록성 가교 방정식([`thm_46`](proofs/qrh_eight_tasks_critical_upgrade.lean#L156-L171))을 완결합니다.
