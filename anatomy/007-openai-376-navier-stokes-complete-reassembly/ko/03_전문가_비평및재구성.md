### 2.1 비영 압력 포텐셜과 무발산 외력의 원문 검증 (`Solenoidal.lean:315-366`)

[`Solenoidal.lean:315-366`](../proofs/oai_ref/lean/OAI/Analysis/PeriodicLattice/Solenoidal.lean#L315-L366)은 원시 외력 `force ν d`에서 압력 포텐셜 `potential d`의 기울기를 빼서 `solenoidalForce ν d`를 정의하고, 푸아송 방정식 `potential_poisson`($\Delta \phi = \operatorname{div} g$)을 이용해 발산이 항등적으로 $0$임을 증명합니다.

```lean
-- 출처: proofs/oai_ref/lean/OAI/Analysis/PeriodicLattice/Solenoidal.lean:315-366
def solenoidalForce (ν : ℝ) (d : Input) : VectorField := force ν d - gradient (potential d)

theorem solenoidalForce_contDiff (ν : ℝ) (d : Input) :
    ContDiff ℝ ∞ (lifted (solenoidalForce ν d)) :=
  (force_contDiff ν d).sub (contDiff_gradient (potential_contDiff d))

theorem solenoidalForce_solenoidal (ν : ℝ) (d : Input) : Solenoidal (solenoidalForce ν d) := by
  intro t ht q
  rw [solenoidalForce, divergence_sub (smooth_slice_differentiable (force_contDiff ν d) t)
    (smooth_slice_differentiable (contDiff_gradient (potential_contDiff d)) t),
    ← Pi.sub_apply, ← Pi.sub_apply, divergence_gradient]
  change divergence (force ν d) t q - laplacian (potential d) t q = 0
  rw [potential_poisson, sub_self]

theorem solenoidalForce_meanZero (ν : ℝ) (d : Input) : MeanZero (solenoidalForce ν d) := by
  intro t ht
  change (∫ q, force ν d t q - gradient (potential d) t q ∂torusVolume) = 0
  rw [integral_sub (smooth_slice_integrable (force_contDiff ν d) t)
    (smooth_slice_integrable (contDiff_gradient (potential_contDiff d)) t),
    force_meanZero ν d t ht, integral_gradient (potential_contDiff d) t, sub_self]

theorem solenoidalForce_equations (ν : ℝ) (d : Input) :
    NavierStokes ν (solenoidalForce ν d) (velocity d) (-potential d) := by
  refine ⟨?_, (equations ν d).2⟩
  intro t ht q
  rw [(equations ν d).1 t ht q, Residual.gradient_zero, Pi.zero_apply, Pi.zero_apply,
    neg_zero, zero_add, gradient_neg]
  change ν • laplacian (velocity d) t q + force ν d t q =
    -(-gradient (potential d) t q) + ν • laplacian (velocity d) t q +
      (force ν d t q - gradient (potential d) t q)
  abel

theorem solenoidalForce_classical_solution (ν : ℝ) (d : Input) :
    ClassicalSolution ν (solenoidalForce ν d) (velocity d) (-potential d) := by
  refine classical_of_smooth_pressure (velocity_contDiff d) (potential_contDiff d).neg ?_
    (solenoidalForce_equations ν d)
  intro t ht
  change (∫ q, -potential d t q ∂torusVolume) = 0
  rw [integral_neg, potential_meanZero d t ht, neg_zero]
```

### 2.2 `PeriodicInverse.lean:183-216`의 `4,528만 배` 여유분 발생 지점과 정밀 재구성

[`PeriodicInverse.lean:183-216`](../proofs/oai_ref/lean/OAI/Analysis/PeriodicLattice/PeriodicInverse.lean#L183-L216) 및 `328-341`을 보면, OpenAI는 `first lam H`의 가중 노름을 평가할 때 $\lambda$의 부호를 구분하지 않고 `Real.exp (lam * s) ≤ Real.exp |lam|`를 적용했습니다.

```lean
-- 출처: proofs/oai_ref/lean/OAI/Analysis/PeriodicLattice/PeriodicInverse.lean:183-200
theorem first_weighted_bound (lam t : ℝ) {H : ℝ → ℝ → ℝ} {w C : ℝ} (hw : 0 ≤ w)
    (hC : ∀ y : ℝ, w * ‖H t y‖ ≤ C) (y : ℝ) :
    w * ‖first lam H t y‖ ≤ ‖(1 - Real.exp lam)⁻¹‖ * Real.exp |lam| * C := by
  have hC₀ : 0 ≤ C := (mul_nonneg hw (norm_nonneg _)).trans (hC 0)
  have hi : ‖∫ s in (0 : ℝ)..1, w * (Real.exp (lam * s) * H t (y - s))‖ ≤ Real.exp |lam| * C := by
    have hz := intervalIntegral.norm_integral_le_of_norm_le_const (a := 0) (b := 1)
      (C := Real.exp |lam| * C) (f := fun s => w * (Real.exp (lam * s) * H t (y - s)))
    apply (by simpa only [sub_zero, abs_one, mul_one] using hz : (∀ s ∈ uIoc (0 : ℝ) 1,
        ‖w * (Real.exp (lam * s) * H t (y - s))‖ ≤ Real.exp |lam| * C) → _)
    intro s hs
    have hs' : 0 ≤ s ∧ s ≤ 1 := by
      rw [uIoc_of_le (by norm_num : (0 : ℝ) ≤ 1)] at hs
      exact ⟨hs.1.le, hs.2⟩
    have he : Real.exp (lam * s) ≤ Real.exp |lam| := by
      apply Real.exp_le_exp.mpr
      calc lam * s ≤ |lam| * s := mul_le_mul_of_nonneg_right (le_abs_self lam) hs'.1
           _ ≤ |lam| := by nlinarith [abs_nonneg lam]
```

**비평 및 재구성**([`ns376_unimported_solenoidal_and_leray_bounds.lean:97-162`](../proofs/ns376_unimported_solenoidal_and_leray_bounds.lean#L97-L162), `thm_07`–`thm_10`):
- `screened (4 * Real.pi)`는 `first (-(4 * Real.pi)) (first (4 * Real.pi) H)`입니다. 두 번째 연산자에서 $\lambda = -4\pi < 0$이므로 $s \in [0,1]$에서 $e^{\lambda s} = e^{-4\pi s} \le 1$입니다. 그런데 위 코드는 `Real.exp |-4*pi| = e^{4\pi} \approx 286,751.31`을 곱해버렸습니다.
- 나아가 $w \cdot \|H(t, y-s)\| \le C$를 적분 밖으로 꺼낸 뒤 양수 커널 $e^{\pm \lambda s}$를 $[0,1]$에서 정확히 적분하면
  $$|1 - e^{\pm \lambda}|^{-1} \int_0^1 e^{\pm \lambda s}\,ds = \frac{1}{|\lambda|}$$
  가 되어 분모 $|1 - e^{\pm \lambda}|$가 항등적으로 소거됩니다. 따라서 `screened (4 * Real.pi)`의 정확한 가중 노름 배율은 $\frac{1}{16\pi^2} \approx 0.006332574$이며, OpenAI의 배율 $\frac{e^{12\pi}}{(e^{4\pi}-1)^2} \approx 286,753.3131$ 대비 **`45,282,268.18`배(`4,528만 배`)** 압축됩니다.

theorem reciprocal_correction_bound {lam s h : ℝ} (hlam : 0 < lam)
    (hs : |s| ≤ h) (hslam : |s / lam| ≤ h) :
    |(lam⁻¹ - 1) * s| ≤ h := by
  have heq : (lam⁻¹ - 1) * s = s / lam - s := by ring
  rw [heq, abs_le]
  obtain ⟨hslo, hshi⟩ := abs_le.mp hs
  obtain ⟨hqlo, hqhi⟩ := abs_le.mp hslam

  · have hq : 0 ≤ s / lam := div_nonneg hsign hlam.le

  · have hq : s / lam ≤ 0 := div_nonpos_of_nonpos_of_nonneg hsign hlam.le
    constructor <;> linarith

## 5. 돌파 #5 원문 비평 및 재구성: 칸토어 부호화(`Encoding.lean`) 및 축대칭 정상 수축(`StationaryContraction.lean`)

[`Material/Encoding.lean:12-16`](../proofs/oai_ref/lean/OAI/MathematicalPhysics/NavierStokes/Material/Encoding.lean#L12-L16)은 허용 자릿수를 `Even d ∧ d + 2 ≤ b`로 정의합니다.

```lean
-- 출처: proofs/oai_ref/lean/OAI/MathematicalPhysics/NavierStokes/Material/Encoding.lean:12-16
def AllowedDigits (b : ℕ) (ds : List ℕ) : Prop :=
  ∀ d ∈ ds, Even d ∧ d + 2 ≤ b

noncomputable def tailBound (b : ℕ) : ℝ := ((b : ℝ) - 2) / ((b : ℝ) - 1)
```

자릿수 $d, d'$가 모두 짝수이고 $d < d'$이면 $d' \ge d + 2$이므로, 두 실린더 구간 사이의 실제 분리 간격은 단일 슬롯 여유분 $\frac{1}{b(b-1)}$이 아니라 $\frac{d+2}{b} - \frac{d + (b-2)/(b-1)}{b} = \frac{1}{b-1}$로서 정확히 **$b$배** 넓습니다([`thm_41`, `thm_42`](../proofs/ns376_detector_margins_and_undecidability_chains.lean#L219-L245)). 또한 아카이브에 함께 포함된 [`HomogeneousDatum.lean`](../proofs/oai_ref/lean/OAI/MathematicalPhysics/NavierStokes/HomogeneousDatum.lean#L1-L65), [`FiniteRankGap.lean`](../proofs/oai_ref/lean/OAI/MathematicalPhysics/NavierStokes/FiniteRankGap.lean#L32-L55), [`StationaryContraction.lean`](../proofs/oai_ref/lean/OAI/MathematicalPhysics/NavierStokes/StationaryContraction.lean#L24-L72) 3개 파일의 동차 스케일링($t^{-1}$), 유한 랭크 강제성 부등식, 바나흐 수축 사상 유리수 예산(`219,422,196 / 8,410,000,000 < 27 / 1000`)을 [`thm_44`–`thm_48`](../proofs/ns376_detector_margins_and_undecidability_chains.lean#L259-L334)에서 완벽히 재검증했습니다.
