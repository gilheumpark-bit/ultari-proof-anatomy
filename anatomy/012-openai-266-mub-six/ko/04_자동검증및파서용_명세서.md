## 2. 해시 봉인 개정 사슬 원장 (`Append-Only Seal Revision Ledger`)

기존 봉인 산출물의 해시를 무단 덮어쓰지 않고, 재작성 사유와 직전 봉인 해시(`prev_sha256`, `Seq 1`)에서 신규 봉인 해시(`entry_sha256`, `Seq 2`)로 이어지는 사슬을 아래와 같이 기록합니다 (`manifest.json`의 `seal_revision_ledger` 및 각 파일 하단 주석에 동시 봉인).

- **개정 차수 및 일시**: `Seq 2` (`2026-11-13`, 직전 기준 커밋 `d31a33e` = `Seq 1`)
- **재작성 사유 (`Rewrite Reason`)**: 외부 공개 시 내부 프롬프트 분류 기호 노출을 방지하기 위해 `.lean` 파일 3종의 상단 주석(`L8`) 및 `problem_spec.md` 제목(`L1`)의 내부 분류 라벨만 일반 학술 문구로 정화하고 각 파일 말미에 `prev_sha256` 출처 주석을 추가함 (정리 선언·증명 코드·수식·줄 번호 변경 `0`건).

```bash
sha256sum -c proofs/checksums.sha256

# 2. Lean 4 커널 컴파일 검증 (0 sorry, 1,249줄 75개 정리)

~/.elan/bin/lean proofs/mub6_weiner_completion_and_gram_sos.lean
~/.elan/bin/lean proofs/mub6_stratigraphy_and_binary64_audit.lean

# 3. 기호·포렌식 검증기 재현 확인
python3 -B proofs/verify_symbolic_mub266.py

# 4. 통합 검증 스위트 실행 (358/358 변이 포착 + Elab MetaM DoF 74/75 + 비선형 14 + oai_ref 69/69 100%)
python3 -B ../../tools/verify_all.py --root .
```
