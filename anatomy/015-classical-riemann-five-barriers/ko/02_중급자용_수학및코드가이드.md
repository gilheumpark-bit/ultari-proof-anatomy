## 2. Paper 1 (Theorems 1-15): 영점 부재 영역의 손계산 여유분 복원과 파예르-리스 벽

### 2.1 극-영점 제곱합(SOS) 분해와 `(3, 4, 1)` 4단계 사다리
비음수 코사인 다항식 $P(\theta) = c_0 + \sum_{k=1}^N c_k \cos(k\theta) \ge 0$을 $-\operatorname{Re}(\zeta'/\zeta)$의 아다마르 전개에 적용할 때, 비자명 영점 항 $-\operatorname{Re}(1/(s-\rho)) < 0$을 부등호 방향 유지 채 버리려면 반드시 $c_k \ge 0$ ($k \ge 1$)이어야 합니다.
이때 $\sigma = 1 + s_1 / M(|t|)$, $1 - \beta = \delta / M(|t|)$, $u = c_0 + A W s_1$ ($W = \sum_{k=1}^N c_k$)로 두면 [`thm_02_pole_zero_sos_decomposition`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L40)이 증명하듯 정확한 제곱합 항등식
$$u \cdot A W \delta(s_1) = u\left(\sqrt{c_1} - \sqrt{c_0}\right)^2 - \left(u - \sqrt{c_0 c_1}\right)^2$$
이 성립합니다. 정류점 $u^* = \sqrt{c_0 c_1}$을 대입하면 [`thm_04_three_four_one_four_tier_slack_cascade`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L78)의 4단계 개선 사다리가 얻어집니다.

- **1단계 (`oai_ref/NonquadraticZeroFree.lean`)**: `K c < 1/32`, 가중치 `9A` 분리로 `A c < 1/288 ≈ 0.003472`
- **2단계 (교과서 `s_1 = 4δ` 고정)**: `1/100 = 0.010000`
- **3단계 (정수 배수 최적해 `s_1 ∈ {6δ, 7δ}`)**: 펠 방정식 `97^2 - 3 * 56^2 = 1` 근사에 의해 `1/70 ≈ 0.014286` (`+42.86%`)
- **4단계 (실수 정류점 `u* = 2√3`)**: `(7 - 4√3)/5 ≈ 0.014359` (`+43.59%`)

여기에 `c_1 / c_2 = 3`인 정수 완전제곱식 $17 + 24\cos\theta + 8\cos 2\theta = (4\cos\theta + 3)^2 \ge 0$을 도입하면 [`thm_08_seventeen_twentyfour_eight_exact_constant_and_gain`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L132)에서 상수가 `(41 - 4√102)/32 ≈ 0.018812` (`+88.12%`, 5차 방정식 $r^5 + 4r^4 - 12r^3 - 40r^2 + 64r - 64 = 0$ 전역 최적해 `0.018819`의 `99.96%`)까지 올라갑니다.

### 2.2 부호 교대 다항식의 세 가지 가중치 규약(`W`, `W_abs`, `W_+`)과 반례 증명
차수 $N$을 무한히 높일 때 무엇이 상수를 막는지 보려면 계수 부호 조건을 엄밀히 구분해야 합니다([`thm_12_general_cosine_pi_weight_lower_bound`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L329)).

1. **아다마르 영점 버림 원뿔 (`c_k >= 0`)**: $W = \sum_{k=1}^N c_k$이며, $\theta = \pi$ 대입에서 $c_0 - c_1 + \sum_{k=2}^N (-1)^k c_k \ge 0 \implies W \ge 2 c_1 - c_0$가 성립합니다.
2. **양방향 바일 상한 모델 (`c_k ∈ ℝ` 부호 무관)**: $|-\operatorname{Re}(\zeta'/\zeta(\sigma + i k t))| \le A M$만 쓰는 모델에서는 분모가 절댓값 합 $W_{\mathrm{abs}} = \sum_{k=1}^N |c_k|$가 되며, 부호 제약 없이 항상 $W_{\mathrm{abs}} \ge 2 c_1 - c_0$가 성립합니다(`c_k >= 0`일 때 $W_{\mathrm{abs}} = W$로 일치).
3. **양수 절단 가중치 `W_+ = ∑ max(c_k, 0)`의 반례**: 만약 부호가 바뀌는 다항식에 $W_+$만 쓰면 $W_+ \ge 2 c_1 - c_0$ 자체가 **거짓**입니다. 실제로 3차 파예르 다항식
   $$\left|1 + \frac{3}{2}e^{i\theta} + \frac{3}{4}e^{2i\theta} - \frac{1}{2}e^{3i\theta}\right|^2 = \frac{65}{16} + \frac{9}{2}\cos\theta + 0\cos 2\theta - \cos 3\theta \ge 0$$
   (`signChangeWitnessC`)은 비음수 코사인 다항식이지만 $W_+ = \frac{9}{2} = \frac{72}{16} < \frac{79}{16} = 2 c_1 - c_0$인 반면, 참된 절댓값 가중치는 $W_{\mathrm{abs}} = \frac{11}{2} = \frac{88}{16} \ge \frac{79}{16}$을 만족합니다.

어느 모델을 쓰든 [`thm_11_fejer_riesz_autocorrelation_strict_two_c0_barrier`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L285)의 $2c_0 - c_1 = a_0^2 + a_N^2 + \sum (a_{j+1}-a_j)^2 > 0$과 결합하면 [`thm_13_fejer_riesz_universal_constant_ceilings`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L378)에 의해 $(\sqrt{c_1}-\sqrt{c_0})^2 / W_{\mathrm{abs}} < (3 - 2\sqrt{2})/3 \approx 0.057191$을 절대 넘지 못하며, [`thm_15_asymptotic_sigma_eq_one_minus_o1_barrier_no_go`](../proofs/classical_dlvp_korobov_and_zero_free.lean#L461)가 `1 - β -> 0`을 결론짓습니다.

## 3. Paper 2 (Theorems 16-35): 영점 밀도 굴절점 이동(`3/4 -> 7/10`)과 `QRH` 그람 결합

- **잉엄-헉슬리 미니맥스**: 잉엄의 3항 균형 $A_{\mathrm{Ing}}(\sigma) = \frac{3}{2-\sigma}$([`thm_16_ingham_three_term_zero_detection_balance`](../proofs/classical_ingham_huxley_zero_density.lean#L29))와 헉슬리의 구간 반사 $A_{\mathrm{Hux}}(\sigma) = \frac{3}{3\sigma-1}$([`thm_20_huxley_k2_k3_amplification_and_cutoff_compatibility`](../proofs/classical_ingham_huxley_zero_density.lean#L178))는 [`thm_21_ingham_huxley_minimax_three_quarters_inflection`](../proofs/classical_ingham_huxley_zero_density.lean#L214)에서 $\sigma^* = \frac{3}{4}$, 정점 $\frac{12}{5} = 2.4$를 형성합니다.
- **구스-메이나드 굴절점 이동**: `3 x 3` 행렬식 에너지 경계 $E_3 \le 2 + \nu(12/5 - 4\sigma)$에서 $k = 2 \to 3$ 교차를 풀면 $A_{\mathrm{GM}}(\sigma) = \frac{15}{5\sigma+3}$이 도출되며, 중간 항 여유분은 제곱합 분자 $250(\sigma - 3/4)^2 + 3/8 > 0$으로 모든 $\sigma > 1/2$에서 자동 양수입니다([`thm_26_guth_maynard_k2_k3_amplification_and_sos_middle_margin`](../proofs/classical_guth_maynard_and_qrh_gram.lean#L23)). 잉엄 곡선과의 새 교차점은 $\sigma^*_{\mathrm{GM}} = \frac{7}{10}$, 정점은 $\frac{30}{13}$입니다([`thm_28_guth_maynard_ingham_seven_tenths_minimax_envelope`](../proofs/classical_guth_maynard_and_qrh_gram.lean#L99), 절감량 $\frac{12}{5} - \frac{30}{13} = \frac{6}{65}$는 [`thm_29_inflection_shift_barrier_saving_and_seventeen_thirtieths_prime_gap`](../proofs/classical_guth_maynard_and_qrh_gram.lean#L135)).
- **`QRH` 3모드 분리와 하이브리드 임계선 균형**: [`thm_32_qrh_three_mode_unbundling_215_and_487_over_3264`](../proofs/classical_guth_maynard_and_qrh_gram.lean#L232)는 임의의 $\delta \in \mathbb{R}$에서 거친 묶음 대비 절감량이 $\frac{1}{24} + \frac{\delta}{16}$ 및 $\frac{1}{8} + \frac{\delta}{16}$임을 먼저 증명한 뒤, `oai_ref/Endpoint.lean`의 $y=0$ 제곱합 꼭짓점 $(4 \cdot 51 \cdot \delta - 79)^2 = 0 \iff \delta = \frac{79}{204}$에서 `215/3264`와 `487/3264`를 산출합니다.
- 또한 [`thm_35_hybrid_ab_coupled_critical_line_fourteen_thirtythirds`](../proofs/classical_guth_maynard_and_qrh_gram.lean#L363)는 역산된 결합식을 쓰지 않고 3개의 기하 구속식(`(35/66, 59/66, 7/11)`)과 임계선($\beta = 1/2$, $\delta = 0$) 필요 절감량 $\Delta_{\mathrm{hyb}} = \frac{29 + 3(\alpha_X + \alpha_Y) - 36\beta}{36} = \frac{14}{33}$에서 직접 거친 묶음 지수 $\frac{13}{44}$와의 적자 $-\frac{17}{132}$ 및 벨치 계수 초과분 $\frac{1}{33}$을 증명합니다.

## 4. Paper 3 (Theorems 36-50): 지겔 영점의 배중률 비효과성과 타원곡선 효과화

1. **에스터만-지겔 4중 오일러 인수 제곱합**: $\chi_1^2 = \chi_2^2 = 1$일 때 [`thm_36_estermann_siegel_biquadratic_euler_factor_sos`](../proofs/classical_siegel_zero_and_ineffectiveness.lean#L21)가 다항식 항등식
   $$4(1+\chi_1)(1+\chi_2) = (1+\chi_1+\chi_2+\chi_1\chi_2)^2 - (\chi_1^2-1)(1+\chi_2)^2 - (\chi_2^2-1)(2+2\chi_1)$$
   로 $(1+\chi_1)(1+\chi_2) \in \{0, 4\}$를 증명하여 디리클레 급수 계수의 비음수성을 보장합니다.
2. **페론 절단 최적화와 배중률 장벽**: 절단 척도 $X = (2 C_0 Q^A)^{2/(2\beta_1 - 1)}$에서 지수 $\frac{2A(1-\beta_1)}{2\beta_1-1} \le \varepsilon \iff \beta_1 \ge 1 - \frac{\varepsilon}{2(A+\varepsilon)}$이 도출되지만([`thm_40_siegel_exponent_threshold_equivalence`](../proofs/classical_siegel_zero_and_ineffectiveness.lean#L87)), 우주의 유령 도체 $q_1$이 커질수록 상수 $C(\varepsilon)$이 0으로 감쇠하여([`thm_41_siegel_implied_constant_decay_with_q1_blowup`](../proofs/classical_siegel_zero_and_ineffectiveness.lean#L114)) 배중률 분기만으로는 계산 가능한 양수 하한을 뽑을 수 없습니다([`thm_42_siegel_two_case_nonconstructive_lem_barrier`](../proofs/classical_siegel_zero_and_ineffectiveness.lean#L135)).
3. **골드펠드-그로스-자기에 대 지겔 속도 교환**: 도체 `5077` 타원곡선의 3중 영점(`ord = 3`)은 계산 가능한 로그 하한 $c \log D$를 주는 대신 지겔의 $c(\varepsilon) D^{1/2-\varepsilon}$ 대비 지수적 속도를 양보합니다([`thm_47_gross_zagier_oesterle_rate_vs_effectivity_tradeoff`](../proofs/classical_siegel_zero_and_ineffectiveness.lean#L281)).

## 5. Paper 4 (Theorems 51-63): 완화제 길이 사다리(`1/2 < 17/33 < 35/66 < 4/7`)와 `κ(θ) < 1` 장벽

- **완화제 길이 사다리**: 대칭 쿠즈네초프 오프대각 한계 $7\theta - 4 < 0 \implies \theta < \frac{4}{7}$([`thm_52_deshouillers_iwaniec_kuznetsov_four_sevenths_barrier`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L43))과 단일 거대소수 `n = d p` 비인수분해 영역의 비대칭 `BCR` 한계 $33\theta - 17 < 0 \implies \theta < \frac{17}{33}$([`thm_53_asymmetric_di_gap_and_bcr_17_33_unfactored_window`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L57)) 사이에 `1/66` 간격의 정확한 서열 $\frac{1}{2} < \frac{17}{33} < \frac{35}{66} < \frac{4}{7}$이 놓입니다([`thm_54_mollifier_kloosterman_scale_ladder_one_sixtysixth`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L67)).
- **미적분 커널 증명과 `κ(θ) < 1` 불가능성**: [`thm_55_mollifier_antiderivative_has_deriv_at_and_boundary_invariant`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L79)가 `HasDerivAt`으로 $\frac{d}{dv}(\frac{1}{2}e^{2Rv}Q(v)^2) = e^{2Rv}Q(v)(RQ(v)+Q'(v))$와 $Q(0)=1, Q(1)=0 \implies J_{AB} = -\frac{1}{2}$를 증명합니다.
- 이어서 [`thm_56_cauchy_schwarz_discriminant_from_nonnegative_quadratic_form`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L104)부터 [`thm_59_finite_theta_strictly_below_hundred_percent_no_go`](../proofs/classical_levinson_conrey_and_mollifier_barrier.lean#L171)까지가 $1 \le 4 I_{AA} J_{BB}$와 $\coth(\omega) > 1$을 결합해 모든 유한 $\theta, R > 0$에서 $c_{\min} > 1$ 및 $\kappa(\theta) < 1$을 확정합니다.

## 6. Paper 5 (Theorems 64-75): 버지스 `r = 2` 제곱합 함정과 킴-사르낙 `7/64` 잔류 장벽

- **버지스 제곱합 함정**: $2r$차 베유 모멘트에서 $h = \frac{1}{2r}$이 최적이며([`thm_64_burgess_weil_moment_balance_optimal_interval_h`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L21)), 횔더 부등식에서 나오는 준볼록성 지수는 [`thm_67_burgess_subconvexity_exponent_sos_trap_at_r_eq_2`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L90)에 의해
  $$E_{\mathrm{Burgess}}(r) - \frac{3}{16} = \frac{r^2 - r + 1}{4r^2} - \frac{3}{16} = \frac{(r - 2)^2}{16 r^2} \ge 0$$
  을 만족합니다.
- 따라서 $r = 2$가 유일한 최소점이고 $r \ge 3$에서는 단조 악화됩니다(`r = 3`이면 `7/36 > 3/16`, [`thm_68_burgess_strict_degradation_for_higher_moments`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L127)). 페트로-영의 3차 모멘트는 대각선 충돌항 `+1`을 소거하여 `1/6 < 3/16` (`1/48` 절감)을 달성합니다([`thm_69_conrey_iwaniec_petrow_young_cubic_collision_removal`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L147)).
- **킴-사르낙 `7/64`와 `Sym^k` 점근 한계**: 란다우 볼록성 한계 $\frac{k+2}{2(k^2+2k+2)}$는 $k=4$ (`GL_5`)에서 $\frac{3}{26}$을 주지만([`thm_72_landau_rankin_selberg_gln_convexity_pole_formula`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L181)), 성격 증폭(`n^2 + 1 -> n(n+1)/2 + 1`)을 결합하면 $\vartheta = \frac{7}{64}$이 도출되며(`3/26 - 7/64 = 5/832` 절감, [`thm_73_kim_sarnak_gl5_character_amplification_seven_sixtyfourths`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L214)), 모든 유한 $k \ge 1$에서 잔류 오차 $0 < \vartheta_k < \frac{1}{2k}$가 남습니다([`thm_74_sym_power_langlands_functoriality_limit_to_ramanujan`](../proofs/classical_burgess_and_kim_sarnak_barrier.lean#L235)).
