# 사례 002: OpenAI `#032` K3 유리 호지 추측 철회본 포렌식 및 형식증명

이 패키지는 OpenAI `#032`(커밋 `adc7f12`)에서 철회된 K3 호지 추측 원고 3편과 인용 논문 `[EEMS13]`을 해부합니다. 모든 결론은 `35`개 독립 Lean 4 정리(`v4.29.0-rc8`, `0 sorry`, 가설 변이 `135/135`건 포착)로 검증했습니다.

## 핵심 해부 결과

1. **심플렉틱 양방향 모순**: 역방향 대각합 $G_2$를 쓰면 교차수 합이 $-2m \neq 0$이 되고, 정방향 대각합 $G_1$으로 바꾸면 차수 2 교차점이 생겨 플로어 곡률 소멸($m_0 = 0$)이 깨집니다.
2. **인용 원문(`[EEMS13]`) 부호 누락**: `min-intersectYETI-final.tex:410, 694`에서 홀수 차원 공 $D^{2k-1}$의 푸앵카레-호프 경계 부호 $(-1)^{\dim U} = -1$이 누락된 지점을 특정합니다.
3. **1부 환원 구출 및 2부 한계 입증**: `Part I`의 클리퍼드 조건부 환원 엔진(`4-7-10` 차수 분리)이 유효함을 확인하고, `Part II`의 7가지 대수적 우회 경로가 막히는 차원 장벽을 증명합니다.
