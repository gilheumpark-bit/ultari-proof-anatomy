## 2. 자동 검증 게이트 실행 명령 및 통과 기준

1. **Lean 4 커널 및 가설 변이 전수 사살 (`408/408`)**:
   ```bash
   ~/.elan/bin/lean proofs/eth_subexp_interpolation_and_hashes.lean && ~/.elan/bin/lean proofs/eth_tensor_contraction_and_circuits.lean && ~/.elan/bin/lean proofs/eth_five_repairs_and_four_layer_verdict.lean
   ```

   * 통과 기준: 종료 코드 `0`, `0 sorry`, `0` 사용자 공리, `50`개 정리의 관계형 가설 `408`건을 개별적으로 `: True`로 치환했을 때 `408/408`건 전수 컴파일 거부(`100%` 사살).
2. **기호(SymPy) + 수치·텐서(PyTorch `FP64`) 결정론적 재현**:
   ```bash
   cd proofs && python3 verify_symbolic_eth.py
   ```
   * 통과 기준: 종료 코드 `0`, PyTorch `FP64` $64 \times 64$ 가환 스왑 연산자 $W_0, M_0$ 스펙트럼, 부록 D 테이퍼드 에르미트 $2$-진 평가치, 4개 층위 수리 후 판정(`audit_8`), 폐기 화석 재조합·수학적 미학 불변량(`audit_9`) 및 갈루아-스왑 3-SAT 솔버·`oai_ref` 5모듈 패치(`audit_10`) 통과, `proofs/symbolic_verification_result.json` 바이트 단위 일치.
3. **핵심 산출물 SHA-256 체크섬 및 무힌트 클린룸 블라인드 대조 (`24/24` 일치)**:

   ```bash
   sha256sum proofs/eth_subexp_interpolation_and_hashes.lean \
             proofs/eth_tensor_contraction_and_circuits.lean \
   ```
