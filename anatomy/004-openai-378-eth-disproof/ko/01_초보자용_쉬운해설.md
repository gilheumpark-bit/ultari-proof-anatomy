# 1단계: 초보자용 쉬운 해설: OpenAI #378 지수 시간 가설(ETH) 반증 감사 가이드

OpenAI #378(지수 시간 가설은 거짓이다)은 상위 저장소 커밋 4eaee87 기준 3,977개의 Lean 4 파일(710,320줄)과 4개의 LaTeX 원고로 이루어져 있습니다. 이 문서는 아지수 시간 3-SAT 알고리즘의 작동 원리, 개발 과정에서 후속 세대로 대체된 1,408개 미임포트 이전 세대 모듈의 정체, 그리고 5가지 형식 명세 경계 설계를 검토·수리했을 때의 결과를 쉽게 설명합니다.



## 1. 아지수 시간 3-SAT 알고리즘의 3대 핵심 원리

변수 $n$개짜리 3-SAT 논리식의 해의 개수를 세는 문제(#3-SAT)는 통상 $2^{\Omega(n)}$의 지수 시간이 걸립니다. OpenAI #378은 세 가지 대수적 기법으로 이를 $2^{O(n/\sqrt{\log n})}$으로 줄였습니다:

1. 가환 스왑 연산자와 이항 스펙트럼 창 ($M_0 = V_0 f_{\mathcal{I}}(W_0)$, [Theorem 1](../proofs/eth_subexp_interpolation_and_hashes.lean#L40-L75)~[Theorem 4](../proofs/eth_subexp_interpolation_and_hashes.lean#L116-L131)):
   - 반대칭 가중치 연산자 $W_0 = \frac{1}{2}\sum_{s=1}^Q (I_D - \Pi_s)$의 고윳값 중복도는 이항분포 $\operatorname{Bin}(Q, \frac{r-1}{2r})$를 따릅니다.
   - 스왑 행렬 $V_0$에 뉴턴 다항식 $f_{\mathcal{I}}(W_0)$을 곱하면 보정 행렬의 랭크($\le \varepsilon D$)와 다항식 차수($\le R-1$)를 동시에 낮출 수 있습니다.
2. 결합 쌍 당김과 차원 $D = r^{2Q}$의 정확한 약분 ([Theorem 5](../proofs/eth_subexp_interpolation_and_hashes.lean#L132-L150)~[Theorem 7](../proofs/eth_subexp_interpolation_and_hashes.lean#L170-L191)):
   - $M$개의 절-변수 결합 쌍을 크기 $D = r^{2Q}$인 묶음으로 나누면 묶음 개수는 $h \le 2M/D$가 됩니다.
   - 여기에 묶음당 랭크 $c_{\mathcal{B}} \le \varepsilon D$를 곱하면 분모와 분자의 $D$가 정확히 약분되어($h \cdot c_{\mathcal{B}} \le 2\varepsilon M$), 최대 변수 차수 $\Delta$가 지수에서 사라집니다.
3. 태너 익스팬더 해싱과 $3n$ 라운드 수축 ([Theorem 10](../proofs/eth_subexp_interpolation_and_hashes.lean#L285-L318)~[Theorem 12](../proofs/eth_subexp_interpolation_and_hashes.lean#L364-L392)):
   - 매 해싱 라운드마다 위양성(spurious) 해 후보가 $\frac{3}{4}$배로 줄어듭니다.
   - $3n$ 라운드를 돌리면 $\left(\frac{3}{4}\right)^{3n} 2^n = \left(\frac{27}{32}\right)^n < 1$이 되어 위양성 후보가 완전히 소거됩니다.



## 2. 4세대 미임포트 이전 세대 모듈(1,408개 파일)과 5대 형식 명세 경계 설계

### 2.1 3,977개 파일 중 미임포트 1,408개 이전 세대 모듈
최종 정리 파일인 [SqrtLogSpace/Final.lean](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Final.lean#L1-L201)에서 실제로 임포트되는 파일은 2,569개이며, 나머지 1,408개(35.4%, 226,053줄)는 후속 세대로 대체된 미임포트 이전 세대 모듈입니다:
- 1세대 (Fixed, 73개 미임포트): 고정 용량($\ell=4096$)으로 $2^{0.9n}$을 증명했으나([ExponentArithmetic.lean:21-86](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/ExponentArithmetic.lean#L21-L86)), $2^{o(n)}$에 도달할 수 없어 후속 세대로 대체되었습니다.
- 2세대 (Subexp, 935개 미임포트, 174,938줄): 변수의 $\Delta$개 슬롯을 한꺼번에 묶는 바람에 이중 지수 폭발이 일어나 $2^{O(n/\log\log n)}$에 갇혔습니다([SubexpParameters.lean:51-115](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SubexpParameters.lean#L51-L115)).
- 3·4세대 (SqrtLog 및 SqrtLogSpace): 결합 쌍 묶음($D = r^{2Q}$)과 표수 3 갈루아 링([RingModel.lean:19-68](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLog/RingModel.lean#L19-L68))을 도입해 증명을 완성했습니다.

### 2.2 5대 형식 명세 경계 설계 감사
1. 자체 고지된 고정 유한 전이표 (미임포트 1세대 [FixedParameters.lean:568-808](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/FixedParameters.lean#L568-L808) 대 활성 4세대 [FiniteFallback.lean:258-299](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/FiniteFallback.lean#L258-L299)): [FiniteFallback.lean:276-277](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/FiniteFallback.lean#L276-L277) 주석에 직접 고지된 대로(Class A 자체 고지), 임계값 이하 유한 구간의 사전 계산은 실행 시간 루프가 아니라 고정 유한 전이표의 일부입니다(1세대 languageScanner, 활성 4세대 FiniteFallback.Scanner). 튜링 기계 정의상 유한 상태 수가 상수($O(1)$)이므로 $O(L)$ 상한을 만족합니다.
2. Mathlib 4 Filter.atTop 기반 $2^{65,535}$ 점근 절단 ([Asymptotics.lean:18-65](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Asymptotics.lean#L18-L65), [NativeLargeEntry.lean:48-61](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/NativeLargeEntry.lean#L48-L61), [Final.lean:44-82](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Final.lean#L44-L82)): sparsifySchedule n이 $n \le 2^{65,535}$ 구간에서 0이 되며(NativeLargeEntry.lean에서는 $2 \le \text{sparsifySchedule } n$, 즉 $2^{209,952}$ 이상에서 성립), NativeLargeEntry.lean은 표준 Mathlib 4 Filter.atTop 추론(Gate 5)으로 존재 임계값을 추출해 그 이하 유한 구간을 FiniteFallback으로 넘겼습니다.
3. Final.lean과 SubexponentialSAT.lean 사이의 Class B 명세 격차 ([ComparatorChallenges/SubexponentialSAT.lean:55, 136-140, 216-217](../proofs/oai_ref/lean/ComparatorChallenges/SubexponentialSAT.lean#L55), [Final.lean:104-148](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Final.lean#L104-L148)): [docs/378.md:9-11](../proofs/oai_ref/lean/docs/378.md#L9-L11)이 정규 인코딩을 고지하고 내부 정리 [Final.lean:104-148](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Final.lean#L104-L148)(exact_count_eth)도 공간 상한을 $n + F.\mathrm{card} + 1$로 적지만, 외부 비교기 명세 exact_count_and_sat(SubexponentialSAT.lean:194-218)는 공간 상한 $S(L+1)^e$를 입력 비트 길이 $L = \text{formulaBitLength } F$ 단독으로만 적었습니다. 빈 논리식($F = \emptyset$)도 해가 $2^n$개라 테이프에 $(n+1)$비트 출력(countWord)을 적어야 하므로($\text{visitedSpace} \ge n$), 이진 인코딩($L = \Theta(\log n)$)에서는 $L$ 단독 다항 공간 상한이 불가능하여 단항 encodeNat($L \ge n$, [NativeLargeEntry.lean:63](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/NativeLargeEntry.lean#L63))이 강제됩니다. 이 점과 $n < 2^{33,554,431}$ 구간의 비균일 유한 전이표가 실제 Class B 명세 격차입니다(비교기 명세 적합성 TIER F).
4. Omega 여유 상수 패딩 ([Theorem 16](../proofs/eth_subexp_interpolation_and_hashes.lean#L450-L463)): 표준 Mathlib 4 선형 산술 전술(omega)을 한 줄로 통과시키려는 + 28700, + 5022741 여유 상수 주입(Gate 5)으로 점근 복잡도 등급에는 영향을 주지 않습니다.
5. 자체 고지된 표수 3(Lean, Engine I) 대 표수 0(LaTeX, Engine II) 범위 분리 ([lean/docs/378.md:9-11](../proofs/oai_ref/lean/docs/378.md#L9-L11), [Theorem 30](../proofs/eth_tensor_contraction_and_circuits.lean#L369-L393), [Theorem 31](../proofs/eth_tensor_contraction_and_circuits.lean#L394-L419)): [lean/docs/378.md:9-11](../proofs/oai_ref/lean/docs/378.md#L9-L11)(Class A 자체 고지)에 명시된 대로 Lean 코드는 표수 3 갈루아 링 기반의 Engine I($2^{O_k(n(\log\log n)^2/\sqrt{\log n})}$)을 증명하며, $(\log\log n)^2$ 인자를 없애는 부록 D(Engine II)와 회로 하한 Corollary 1.4는 LaTeX 원고에만 수록되어 있습니다.



## 3. 5대 형식 명세 경계 격차 수리 후 6계층 최종 판정

1. 1계층, 형식 공간 명세 ([SubexponentialSAT.lean:216](../proofs/oai_ref/lean/ComparatorChallenges/SubexponentialSAT.lean#L216) 대 [Final.lean:104-148](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/Final.lean#L104-L148)): 수리 전에는 단항 패딩($L \ge n$)으로 L 단독 공간 상한이 참(True)이었으나, 표준 이진 인코딩($L = \Theta(\log n)$, $n = 2^{20}$에서 49,000 < 1,048,576)에서는 $n$비트 출력 기록조차 불가능해 Class B 비교기 명세가 참에서 거짓으로 바뀌며 exact_count_eth의 $n + F.\mathrm{card} + 1$ 명세로 개정해야 합니다(비교기 명세 적합성 TIER F, [Theorem 33](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L32-L51), [Theorem 34](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L52-L75)).

2. 2계층, 회로 하한 따름정리 ([quantitative-circuits.tex:15-65](../proofs/oai_ref/tex/quantitative-circuits.tex#L15-L65)): 원고는 미형식화 Engine II로 $\Omega(n\sqrt{\log n})$을 증명합니다. Lean 4에 구현된 Engine I만 쓰면 $\Omega(n\sqrt{\log n}/(\log\log n)^2)$으로 약화되므로, 원래 하한을 유지하려면 부록 D 형식화가 필요합니다([Theorem 35](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L76-L93), [Theorem 36](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L94-L115)).

3. 3계층, 유한·물리 영역 ($n < 2^{33,554,431}$): 수리 전에는 비구성적 [FiniteFallback](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/FiniteFallback.lean#L242-L299) 고정 전이표 또는 [reject](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLogSpace/HighQueryProgram.lean#L50-L52)를 사용했습니다. Class B 비균일 전이표를 균일 루프로 수리하면 [LeafParametersProgram.lean:101](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLog/LeafParametersProgram.lean#L101)(4R ≤ Q)과 [CostAssemblyFinal.lean:53-54](../proofs/oai_ref/lean/OAI/Algorithms/SubexponentialSAT/SqrtLog/CostAssemblyFinal.lean#L53-L54) 조건에 의해 $2^n$ 전수조사로 작동합니다([Theorem 37](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L116-L139)~[Theorem 40](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L181-L206)).

4. 4계층, 점근 극한 계층 ($n \to \infty$ ETH 반증): 대수적 차수 축소 엔진 자체가 유효하므로 명세 경계 격차를 모두 수리한 뒤에도 $n \ge N_0(k)$에서 $2^{o(n)}$ 복잡도와 ETH 반증 결론은 그대로 보존됩니다([Theorem 41](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L207-L225), [Theorem 42](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L226-L260)).

5. 5계층, 이전 세대 모듈 하이브리드 계층: 미임포트 2·3세대 모듈을 결합하면 가드 활성화 임계치가 $\log_2 L = 25$에서 $15$로($1,024$배), 지수 상수가 12,032,411,847에서 70,023으로($171,835$배) 압축됩니다([Theorem 43](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L261-L293)~[Theorem 46](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L344-L374)).

6. 6계층, 갈루아 링 솔버 및 5모듈 패치: 부록 D([Theorem 21](../proofs/eth_tensor_contraction_and_circuits.lean#L120-L156)) 형식화에 더해 $\mathrm{GR}(3^3, 2)$ 헨젤 리프트, 테이퍼드 에르미트 복원, 실행형 갈루아 링 3-SAT 솔버 및 5개 모듈 직접 패치를 완결했습니다([Theorem 47](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L375-L403)~[Theorem 50](../proofs/eth_five_repairs_and_four_layer_verdict.lean#L447-L461)).
