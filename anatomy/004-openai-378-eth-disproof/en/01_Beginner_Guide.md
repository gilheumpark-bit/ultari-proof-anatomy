## 1. Question 1: Origin of the Hardcoded Constants and Algebraic Constructions (Key Trick Extraction)

OpenAI `#378` reduces the deterministic time complexity of counting solutions to an $n$-variable `3-SAT` formula (`#3-SAT`) from $2^{\Omega(n)}$ down to $2^{O(n/\sqrt{\log n})}$. Every seemingly arbitrary constant in the paper and code emerges from a tight system of equations:

1. **Commuting Swap Involution Matrix and Binomial Spectral Window ($M_0 = V_0 f_{\mathcal{I}}(W_0)$, [`Theorem 1`](../proofs/eth_subexp_interpolation_and_hashes.lean#L22-L50)–[`Theorem 4`](../proofs/eth_subexp_interpolation_and_hashes.lean#L95-L106))**:
   - When multiple clauses share the same variable, eliminating non-monotone disagreement terms using the identity matrix $I_D$ leaves up to $Q$ mismatched slots (blowing up polynomial degree to $Q$), whereas using the full swap matrix $V_0 = \prod_{s=1}^Q \Pi_s$ blows up the linear summary rank $\operatorname{rank}(I_D - V_0) = \Theta(D)$.
   - The AI's key algebraic invention is the antisymmetric weight operator $W_0 = \frac{1}{2}\sum_{s=1}^Q (I_D - \Pi_s)$. Its eigenvalue multiplicity follows the exact binomial distribution $\operatorname{Bin}(Q, \frac{r-1}{2r})$, concentrating almost all weight inside a narrow spectral window $\mathcal{I}$ of width $R \asymp \sqrt{Q\lambda}$ around the mean.
   - Multiplying $V_0$ by the degree-$(R-1)$ Newton forward-difference polynomial $f_{\mathcal{I}}(W_0)$ (which equals $(-1)^w$ on $w \in \mathcal{I}$) yields $M_0 = V_0 f_{\mathcal{I}}(W_0)$, simultaneously achieving **exponentially small correction rank $c_{\mathcal{B}} = \operatorname{rank}(I_D - M_0) \le \varepsilon D$ and low mismatch degree $|E_{u,y}| \le R - 1 \ll Q$**.
2. **Incidence-Pair Pullback and Exact Cancellation of $D = r^{2Q}$ ([`Theorem 5`](../proofs/eth_subexp_interpolation_and_hashes.lean#L111-L125)–[`Theorem 7`](../proofs/eth_subexp_interpolation_and_hashes.lean#L149-L161))**:
   - Partitioning $M$ clause-variable incidence pairs into complete buckets of size $D = r^{2Q}$ produces $h \le 2M/D$ buckets. When multiplied by the per-bucket summary rank $c_{\mathcal{B}} \le \varepsilon D$, **the dimension $D$ cancels out identically between numerator and denominator** ($h \cdot c_{\mathcal{B}} \le 2\varepsilon M$), eliminating the maximum degree $\Delta$ from the exponent.
3. **Tanner Expander Constants $P = 20000 B^2\mu^2$, $D_0 = 320000 B^2\mu^3$, and $3n$ Hash Rounds ([`Theorem 10`](../proofs/eth_subexp_interpolation_and_hashes.lean#L238-L266)–[`Theorem 12`](../proofs/eth_subexp_interpolation_and_hashes.lean#L317-L339))**:
   - Setting $\delta = \frac{1}{100B\mu}$ and $\varepsilon = \frac{\delta}{2}$ in the expander mixing inequality uniquely fixes the candidate hash list size $P = \frac{1}{\delta(\delta-\varepsilon)} = 20000 B^2\mu^2$ and minimum distance $D_0 = 16\mu P = 320000 B^2\mu^3$.
   - Each greedy round shrinks false witnesses by $\frac{3}{4}$; running $2n$ rounds diverges as $\left(\frac{3}{4}\right)^{2n} 2^n = \left(\frac{9}{8}\right)^n > 1$, so **$3n$ rounds** are the minimum integer multiple per variable giving $\left(\frac{3}{4}\right)^{3n} 2^n = \left(\frac{27}{32}\right)^n < 1$.

Abandoned because constant capacity cannot reach $2^{o(n)}$.
