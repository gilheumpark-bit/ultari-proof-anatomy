# OpenAI `#378` (지수 시간 가설 ETH 반증) 전산학자·심사위원 6단계 심층 검증, 4세대 화석 고고학, 5대 해킹 수리 및 4개 층위 판정 패키지

이 패키지는 OpenAI `#378` (*The Exponential Time Hypothesis is False*, `OAI.Algorithms.SubexponentialSAT`, `3,977`개 `.lean` 파일 `710,320`줄 및 `4`개 `.tex` 파일 `5,888`줄)을 대상으로 **이론전산학자와 저널 심사위원(Referee)이 실제로 묻는 6대 핵심 질문**을 백지상태(`First Principles`) 6단계 수식 재계산, `1,408`개 폐기 화석 파일(`226,053`줄) 고고학, 5대 보상 해킹 해부 및 수리 후 4개 층위 정밀 판정, `42`개 순수 구조 `Lean 4` 증명(`331/331` 가설 변이 사살), Blackwell GPU 시뮬레이션, 그리고 무힌트 클린룸 독립 블라인드 테스트(`24/24` 일치)로 완전 해부한 심층 검증 패키지입니다.
