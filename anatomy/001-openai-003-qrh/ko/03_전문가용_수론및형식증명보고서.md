## 3. 지수 평형 관계식, $z_{\text{re}} = 1/6$ 수렴 경계, $m \ge 2$ 꼬리항 분석 (`Theorems 18~20`)

### 3.1 지수 평형 관계식 ([`Theorem 18`](../proofs/qrh_exponent_and_parameter_bounds.lean#L234-L250) 증명)
`LowGramScale.lean`($\alpha_X = 17/48, \alpha_Y = 23/48 \implies \gamma_{\text{det}} = 3/16$), `PrincipalMellinResidues.lean:392`($s + 1/6 - 1 = s - 5/6$), `PrincipalSignalComparison.lean:411`($c_{\text{signal}} = -5/6 + \alpha_X/3 + \ell/6 = -11/16$), `CommonProbe.lean:19-21`을 결합하면 무영점 경계 $\beta$의 관계식이 도출됩니다:
$$\beta(\alpha_X, \alpha_Y, \ell, \Delta_{\text{Gram}}) = \frac{5}{6} + \frac{\alpha_X + \alpha_Y - 2\ell}{12} - \Delta_{\text{Gram}} = \frac{7}{8} - \Delta_{\text{Gram}}$$

### 3.2 $z_{\text{re}} = 1/6$ 수렴 경계 조건 ([`Theorem 19`](../proofs/qrh_exponent_and_parameter_bounds.lean#L258-L268) 증명)
1. **비주항 가우스 합 분기 `(0, 2, 0, m=1)` (`HighRowsCentralTerms.lean:47-53`)**: 지수 조건 $6 - 2(1+3x) - 6z_{\text{re}}(1) \le \frac{1}{2} - x$는 $x \to \frac{1}{2}$에서 $6z_{\text{re}} \ge 1 \iff z_{\text{re}} \ge \frac{1}{6}$을 요구합니다.
2. **주지표 데데킨트 제타 극점 (`PrincipalRemainderBounds.lean:577-598`)**: 주지표 $\pi$의 6차 가우스 합 급수는 $L(\pi, 6z)$로 합산되며 $z = \frac{1}{6}$에서 단순 극점을 가집니다. 적분 경로를 $z = \frac{33}{200} = 0.165 < \frac{1}{6}$로 이동할 때의 절약량은 $\frac{13}{16}\left(\frac{1}{6} - \frac{33}{200}\right) - \frac{1}{1000} = \frac{13}{9600} - \frac{1}{1000} = \mathbf{\frac{17}{48000}}$ (`ParametersHighData.lean:45`의 `principal_budget`)입니다.

### 3.3 $m \ge 2$ 기하 급수 꼬리항의 수렴 조건 완화 ([`Theorem 20`](../proofs/qrh_exponent_and_parameter_bounds.lean#L273-L294) 증명)

### 7.1 과제 1: $4 \le Q < 480$ 소수 노름 하한 제거 및 유한 나쁜 소수 마스크 흡수 (정리 28~30)

   - `HighRowsCentralQuotient.lean:9`의 `480 ≤ Q` 가설은 전역 오일러 곱이 아니라 다이아딕 소수 풀 $P \in T_j$ (`CubePrimeBound.lean:105`)에서만 호출됩니다. `CubePrimeThresholds.lean:13-33` (`central_pool_good_eventually`)이 $Q \ge c Z^{d_{\min} r_{\min}} \to \infty$를 이용해 모든 중심 풀 소수에서 `480 ≤ Q`를 무조건부로 방출합니다.

2. **$(1 - V)^{-1}$ 분모 항등 약분 및 $480 \to 112$ 축소 (`theorem_28_marked_factor_singularity_cancels_identically`, `theorem_29_all_small_eisenstein_norms_nonvanishing`, `theorem_30_universal_finite_bad_prime_mask_absorption`)**:

### 7.2 과제 2: $m=1$ 유수 구조 해부 및 2·3차 오일러 연속 (정리 31~34, 39)
1. **2차 오일러 연속 인자(`secondContinuedCorrection`) 및 5개 1차항 완전 상쇄 (`theorem_31_second_continuation_exact_polynomial_identity`)**:
   - $\text{secondContinuedCorrection}(R, V, W, D, P^*) := (1 - R) \cdot \text{continuedCorrection}(V, W, D, P^*)$로 정의하면,
     $$(1 - D)\big(\text{secondContinuedCorrection} - 1\big) = -VW + WD - RW^2 + RVW + (1 - W)(-R q_{\text{inv}} - KV + VD - VWR)$$
     가 성립하여 1차 단순극 잔여항 5개(`1 - 1 = 0`, `-R + R = 0`, `-D + D = 0`, `+WR - WR = 0`, `+RD - RD = 0`)가 항등적으로 소멸합니다(`theorem_31_second_continuation_exact_polynomial_identity`).
2. **$z_{\text{re}}$ 오일러 꼬리 수렴 장벽 하향 및 `sourceExponent`의 $z_0$-불변성 (`theorem_32_second_and_third_continuation_convergence_barrier`, `theorem_33_central_exponent_z0_invariance_at_d0`, `theorem_34_universal_z0_shift_improves_subcritical_d`, `theorem_39_m1_sextic_pole_residue_and_33_200_remainder_saving`)**:

### 7.3 과제 3: 기저 지수 `3/16` 및 신호 지수 `-11/16`의 마스터 결합 방정식과 재스케일링 해부 (정리 35~40)
