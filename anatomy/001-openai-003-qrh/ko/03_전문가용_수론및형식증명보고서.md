## 3. 지수 평형 관계식, $z_{\text{re}} = 1/6$ 수렴 경계, $m \ge 2$ 꼬리항 분석 (`Theorems 18~20`)

### 3.1 지수 평형 관계식 ([`Theorem 18`](../proofs/qrh_exponent_and_parameter_bounds.lean#L234-L250) 증명)
`DirichletL/Detector/LowGramScale.lean`($\alpha_X = 17/48, \alpha_Y = 23/48 \implies \gamma_{\text{det}} = 3/16$), `DirichletL/PrincipalMellinResidues.lean:392`($s + 1/6 - 1 = s - 5/6$), `DirichletL/PrincipalSignalComparison.lean:411`($c_{\text{signal}} = -5/6 + \alpha_X/3 + \ell/6 = -11/16$), `DirichletL/Hecke/CommonProbe.lean:19-21`을 결합하면 무영점 경계 $\beta$의 관계식이 도출됩니다:
$$\beta(\alpha_X, \alpha_Y, \ell, \Delta_{\text{Gram}}) = \frac{5}{6} + \frac{\alpha_X + \alpha_Y - 2\ell}{12} - \Delta_{\text{Gram}} = \frac{7}{8} - \Delta_{\text{Gram}}$$

### 3.2 $z_{\text{re}} = 1/6$ 수렴 경계 조건 ([`Theorem 19`](../proofs/qrh_exponent_and_parameter_bounds.lean#L258-L268) 증명)
1. **비주항 가우스 합 분기 `(0, 2, 0, m=1)` (`DirichletL/Detector/HighRowsCentralTerms.lean:47-53`)**: 지수 조건 $6 - 2(1+3x) - 6z_{\text{re}}(1) \le \frac{1}{2} - x$는 $x \to \frac{1}{2}$에서 $6z_{\text{re}} \ge 1 \iff z_{\text{re}} \ge \frac{1}{6}$을 요구합니다.
2. **주지표 데데킨트 제타 극점 (`DirichletL/Detector/PrincipalRemainderBounds.lean:577-598`)**: 주지표 $\pi$의 6차 가우스 합 급수는 $L(\pi, 6z)$로 합산되며 $z = \frac{1}{6}$에서 단순 극점을 가집니다. 적분 경로를 $z = \frac{33}{200} = 0.165 < \frac{1}{6}$로 이동할 때의 절약량은 $\frac{13}{16}\left(\frac{1}{6} - \frac{33}{200}\right) - \frac{1}{1000} = \frac{13}{9600} - \frac{1}{1000} = \mathbf{\frac{17}{48000}}$ (`DirichletL/ParametersHighData.lean:45`의 `principal_budget`)입니다.

### 3.3 $m \ge 2$ 기하 급수 꼬리항의 수렴 조건 완화 ([`Theorem 20`](../proofs/qrh_exponent_and_parameter_bounds.lean#L273-L294) 증명)
