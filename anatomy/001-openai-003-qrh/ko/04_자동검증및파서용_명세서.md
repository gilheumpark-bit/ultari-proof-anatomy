## 1. 검증 실행 명령어 (Verification Commands)

패키지 루트 디렉터리에서 아래 명령어를 실행하여 총 48개 Lean 4 커널 증명(`exit 0`), SymPy 기호 연산 재현, SHA-256 해시 일치를 확인합니다.

```bash
# 1. Lean 4 커널 컴파일 검증 (정리 1~27 및 정리 28~48, 종료 코드 0 및 경고/오류 0건 확인)

# 2. 기호 연산 스크립트 실행 및 JSON 산출물 재현 확인
cd proofs && python3 verify_symbolic_qrh.py && cd ..

# 3. 핵심 산출물 5종의 SHA-256 해시 대조
sha256sum proofs/qrh_exponent_and_parameter_bounds.lean \
          proofs/qrh_continuation_and_rescaling.lean \
          proofs/verify_symbolic_qrh.py \
          proofs/symbolic_verification_result.json \
          proofs/problem_spec.md
```

## 3. 해석상 유의사항 (Scope Notes)

1. **유리수·정수 형식 증명과 복소해석적 과제의 구분**:
   - [`proofs/qrh_exponent_and_parameter_bounds.lean`](../proofs/qrh_exponent_and_parameter_bounds.lean) (정리 1~27) 및 [`proofs/qrh_continuation_and_rescaling.lean`](../proofs/qrh_continuation_and_rescaling.lean) (정리 28~48)의 총 48개 정리는 유리수(`Rat`) 및 자연수·정수(`Nat`/`Int`) 위에서 대수적 파라미터 예산, SOS 다항 항등식, $m \ge 2$ 가우스 값매김 표 소멸, 개별 행렬 스케일 지수 차이($\frac{215}{3264}$ 및 $\frac{487}{3264}$), $(w,z)$ 경로 이동 예산, 2·3차 오일러 연속 다항식 상쇄, 마스터 스케일 결합 방정식, 그리고 26개 모듈(`178`개 선언문) 1:1 전수 감사(지겔 영점 국소 고립 베주 원뿔 동차화 및 산술 절단 전달 포함)를 커널 증명합니다.
   - 반면 분리된 $m=1$ 유한항의 복소해석적 멜린 연속 적분과 $L^2$ 연산자 노름 평가는 향후 복소해석 형식화 과제에 해당하므로, 본 패키지가 리만 가설 전체를 단독 해결했다고 요약해서는 안 됩니다.
2. **JSON 매니페스트 참조**:
   - 각 문제의 출력 키와 48개 정리의 줄 번호 매핑은 [`manifest.json`](../manifest.json)에 수록되어 있습니다.
