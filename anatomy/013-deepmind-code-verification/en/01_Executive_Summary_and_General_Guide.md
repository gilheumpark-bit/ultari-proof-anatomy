## Six-Step Plain-Language Walkthrough

1. Excluded Build Layer and Uncommitted AGPL-3.0-only Binary: Plain lake build (@[default_target] in [lakefile.lean](../proofs/oai_ref/lakefile.lean#L1-L120)) compiles 10,722 modules while skipping the 120 CliElfLib modules (85,249 lines). Furthermore, the 617,448-byte ELF (SHA-256: 2f20c836...) is compiled from AGPL-3.0-only libsignal source and gitignored from the Apache-2.0 repository, with Rust header line numbers frozen because panic source lines are baked into the verified machine code. Separately, LibsignalBinary/Heap/ (including 22 SYNC.txt-mirrored entries) is imported by 0 headline theorems.
2. The 85.94% Hook Cut-Plane, Crypto/Zeroize Implementation Gap, and Side-Channel Absence: At 55 of 64 tracked symbol addresses (45 after PR #2), the stepper skips ELF instructions and applies an idealized mathematical state transition. Distinct from abstract hardness assumptions in protocol games, hooking Curve25519, SHA-256/512, AES-256-CBC, ML-KEM-768/1024, and 2 `Drop::drop` zeroization symbols leaves compiled AArch64 crypto implementation correctness (cf. `HACL*`/`Fiat-Crypto`/`s2n-bignum`), compiler dead-store elimination of RAM/stack zeroization, and timing/cache side-channel resistance unverified.
3. Self-Disclosed Harness Scope (Zero-Padded Coins RNG, Frozen Unix Epoch Clock, and Single-Poll Flat Files): Production Signal clients rely on OS CSPRNGs, wall-clock key rotation, multi-threaded async SQLCipher storage, and network retries. Within harness bounds self-disclosed in DeepMind's manuscript and `DEVIATIONS.md`, the verified CLI pads exhausted `coins.rs` buffers with 0 bytes under `CryptoRng`, pins time to `SystemTime` at Unix epoch 0 (`DEV-PQ8`) so 30-day SPK/session expiration (`DEV-PQ9`) never fires, and treats closed stdio `EBADF = 9` as silent EOF/success.
4. Pre-Boot 5-Byte Patch, udf #0 Stubs, and OutOfMemory Excusal: Because Eval.lean faults on MRS, cliTokenPatchPlaced zeroes 5 .data bytes before starting main, while [alink_check.py](../proofs/oai_ref/scripts/stock-pin/alink_check.py#L21-L31) binds unresolved Class Z externs and 3 displaced weak outline atomics to 4-byte udf #0 (0x00000000) trap stubs. In Mmap.lean, exceeding 1 GiB halts in .OutOfMemory instead of returning -ENOMEM, excusing caller null-pointer paths (DEV-CLI15).
5. Classical-Only DEV-PQ19 Scope and $2^{40}$ Standard-Model Vacuity: Despite naming PQXDH and SPQR, computational headlines claim classical security only (DEV-PQ19), and at $q_{\mathrm{total}} = 2^{40}$ the $2^{96.00}$ reduction step budget pushes standard-model Curve25519 4-leg GapDH Term 5 to $17,441 / 16,384 > 1$ (upstream concedes at PQXDH.md:107-115 that $2^{40}$ cannot instantiate a concrete 128-bit bound and retreats to $q_{\mathrm{total}} \le 2^{24}$). Furthermore, X25519+XEdDSA key reuse (DEV-PQ13) leaves GapSigEufCma and GapDhWithSign Forking-Lemma square-root loss in standalone XeddsaRom/ outside the Lean TCB, DEV-PQ16 enforces prime-order P.isCanonical guards with torsion checks hooked in binary placement, and DEV-PQ17 quotients GapDhWithSign modulo cofactor-8 torsion cosets (pow8, [DEVIATIONS.md](../proofs/oai_ref/Computational/docs/DEVIATIONS.md#L1894-L1922)) with an $O(q_{\mathrm{total}}^2)$ DDH oracle budget.
6. Two Operational Cliffs (35,211 Messages and 56,680 Handshakes): Under per-message epoch advancement ($q_{\mathrm{ep}} = q$), Signal's 64-bit wire MAC pushes the SPQR V1 bound (DEV-C14) past 1 at $q = 35,211$ messages (whereas a 16-byte MAC shifts vacuity to $q = 2,307,621,357 > q_{\mathrm{u32,\max}}$), and appending 37 bytes per handshake to .base-keys writes $2,097,160 > 2,097,152$ bytes (2 MiB) at handshake 56,680, permanently rejecting new prekey messages referencing that unrotated last-resort Kyber prekey from handshake 56,681 onward.
