## 1. 5단계 인과 사슬 분석

1. **1단계 (증명 장벽 및 상태 폭발 한계)**: `rustc 1.98.1`과 musl `libc.a`로 정적 컴파일된 `libsignal-cli` AArch64 바이너리(`617,448`바이트, `AGPL-3.0-only` 파생물로 `.GeneratedLean/`에 격리)를 IND-CCA·전방향 안전성(FS)·침해 후 안전성(PCS) 암호 게임에 직접 연결하려 하면 두 가지 장벽이 발생합니다. 첫째, Curve25519·ML-KEM-768/1024·SHA-256/512·AES-256-CBC 기계어 루프와 `Drop::drop` 영점화를 모두 기호 실행하면 **`7,528,295`줄** 규모의 저장소([`lakefile.lean`](../proofs/oai_ref/lakefile.lean#L1-L120))에서도 명령어 분기가 폭발합니다. 둘째, 실제 리눅스 커널의 시스템 레지스터 탐지(`MRS`), ASLR 무작위 배치, 실시간 시계 만료, `mmap` 메모리 고갈 반환(`-ENOMEM`)이 순수 프로토콜 상태 기계와 충돌합니다.
2. **2단계 (절단면 기전, Rust CLI 하네스 고정 및 커널 투영 설계)**: 이 장벽을 우회하기 위해 업스트림은 4단 절단면을 작동시킵니다. (i) [`coins.rs`](../proofs/oai_ref/third_party/libsignal/libsignal-session/cli/src/coins.rs#L32-L46)와 [`cli/src/lib.rs`](../proofs/oai_ref/third_party/libsignal/libsignal-session/cli/src/lib.rs#L140-L235)가 `0` 패딩 입력 버퍼를 `CryptoRng`로 감싸고 시계를 `UNIX_EPOCH`(`0`)에 고정해 `30`일(`2,592,000`초) 서명 프리키 만료를 건너뛰며, (ii) 링커 스크립트 [`stock.ld`](../proofs/oai_ref/third_party/libsignal/libsignal-session/cli-elf/stock.ld#L30-L94)와 [`alink_check.py`](../proofs/oai_ref/scripts/stock-pin/alink_check.py#L21-L31)가 `:text_a`(`< e_entry`, Rust 크레이트 및 `4`바이트 `udf #0` Class `Z` 스텁)와 `:text_b`(`>= e_entry`, `_start`·musl·`mallocng`)를 분리하고, (iii) [`CliBinaryPq.lean`](../proofs/oai_ref/LibsignalBinary/Specifications/SignalSession/CliBinaryPq.lean#L249-L262)의 `cliExternsPlacedSig`가 `64`개 외부·패닉 심볼 중 `55`개(`Drop::drop` 영점화 `2`개 포함)를 명령어 인출 전에 가로채 이상화된 상태 전이로 치환하며, (iv) [`Hoare.lean`](../proofs/oai_ref/arm64-semantics/Arm64/Trusted/Spec/Hoare.lean#L160-L262)과 [`Mmap.lean`](../proofs/oai_ref/arm64-semantics/Arm64/Trusted/Syscalls/Mm/Mmap.lean#L1-L120)이 비모델링 시스콜과 메모리 부족을 `.Exception` 및 `.OutOfMemory` 정지 상태로 투영합니다.
3. **3단계 (`PQXDH.md` `2^40` 공허화 및 `8`바이트 MAC 다항식 유도)**: [`PQXDH.md`](../proofs/oai_ref/Computational/docs/PQXDH.md#L69-L112)와 [`READING_THE_THEOREMS.md`](../proofs/oai_ref/Computational/docs/READING_THE_THEOREMS.md#L160-L188)에서 `deploymentSetup`의 GapDH 계수는 $c_3 = 2^{60} + 2^{56} + 2^{51} + 2^{46} = \frac{17441}{16384} \cdot 2^{60}$이며, $q_{\text{total}} = 2^{40}$에서 스텝 예산 $t' \approx 2^{96.00}$을 표준 모델 제곱 공격 비율 $(t')^2 / 2^{252} = 2^{-60}$에 대입하면 제5항이 $c_3 \cdot 2^{-60} = \frac{17441}{16384} > 1$로 공허화됩니다. 한편 [`LibsignalBound.lean`](../proofs/oai_ref/Computational/Specifications/Session/ACD19/Ratchet/LibsignalBound.lean#L42-L49)(`DEV-LS31`)과 [`StatementComposed.lean`](../proofs/oai_ref/Computational/Specifications/Session/StatementComposed.lean#L427-L505)(`DEV-C14`)의 `8`바이트 절단 MAC 분자는 $q_{\text{ep}} = 0$에서 모든 $q \ge 2$에 대해 SPQR V1 합성 상한이 더 큽니다:
   $$80 q^2 + 56 q - (48 q^2 + 96 q) = 32 q^2 - 40 q = 8 q (4 q - 5)$$
   또한 [`LibsignalBound.lean`](../proofs/oai_ref/Computational/Specifications/Session/ACD19/Ratchet/LibsignalBound.lean#L42-L45)이 `4 * macForgeryTerm`을 슬롯 합(`fsSlotCount`) 밖으로 묶어내지 않으면 슬롯 계수 $2(4q + 25001)q$가 곱해집니다:
   $$2(4q + 25001) q = 8 q^2 + 50002 q$$
4. **4단계 (임계치 모순 적발·먹통 절벽·디코더 절감)**: $\operatorname{macC14}(q, q) \ge 2^{64}$를 풀면 `DEVIATIONS.md`의 `DEV-C14`가 구버전 `DEV-LS31`의 `q = 38,967`을 그대로 복사한 수리적 오류가 드러납니다. 실제 공허화(`>= 1`)는 **`q = 35,211`**에서 이미 발생하며 `q = 38,967`에서는 분자가 `27,670,763,479,788,465,276`($> 1.5 \times 2^{64}$)에 달합니다. 또한 [`PqDir.lean`](../proofs/oai_ref/LibsignalBinary/Specifications/SignalSession/PqDir.lean#L110-L315)과 [`stores.rs`](../proofs/oai_ref/third_party/libsignal/libsignal-session/cli/src/stores.rs#L420-L445)의 `.base-keys` 파일(`37`바이트/키)은 **`56,680`번째 핸드셰이크**($37 \times 56680 = 2,097,160$)에서 `FILE_CAP`($2^{21} = 2,097,152$)을 초과하는 크기를 디스크에 기록해 **`56,681`번째 핸드셰이크부터** 미회전 최후수단 Kyber 프리키 수락이 영구 먹통이 됩니다. 한편 기계어 디코드 보조정리 $k$개를 반사 테이블로 압축하면 정확히 다음 줄 수가 절감됩니다:
   $$14 k - (120 + k) = 13 k - 120$$
5. **5단계 (정수·비트벡터 형식화 및 가설 변이 검증)**: 부동소수점 반올림이나 `sorry` 없이 모든 지층 합산, 위생 스크립트 사멸 부채, Rust 하네스 상수, 비트벡터 ABI 괴리, 다항식 임계치를 Lean 4 커널 안에서 결정론적으로 증명하기 위해 `Int`, `Nat`, `Bool`, `BitVec`(`64`/`32`/`8`) 기반 **`81`개 정리(`1,457`줄)**를 구축했고, 전칭 가설 변이 시험에서 **`391/391` (`100%`) 전원 포착**을 확인했습니다.
