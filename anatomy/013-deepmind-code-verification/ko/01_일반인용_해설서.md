## 비전공자를 위한 6단계 직관적 해부

1. 기본 빌드 제외 지층과 미커밋 AGPL-3.0-only 바이너리: [lakefile.lean](../proofs/oai_ref/lakefile.lean#L1-L120) 기본 타깃에는 10,722개 모듈만 포함되고 CliElfLib 전용 120개 모듈(85,249줄)은 제외됩니다. 더 나아가 증명이 가리키는 617,448바이트 ELF(SHA-256: 2f20c836...)는 Signal의 AGPL-3.0-only 코드에서 파생되어 Apache-2.0 저장소에 커밋되지 않으며, 소스 헤더 줄 번호가 패닉 기계어에 박혀 있어 주석 한 줄도 바꿀 수 없습니다. 한편 LibsignalBinary/Heap/(22개 SYNC.txt 미러 파일 포함)은 어떤 헤드라인 정리도 임포트하지 않는 고립 지층으로 남아 있습니다.
2. 85.94% 심볼 Hook 우회와 암호 구현·영점화 dead-store·부채널 공백: 64개 추적 심볼 중 55개(PR #2 이후 45개) 호출 지점에서 기계어 실행을 멈추고 이상화된 Lean 함수를 호출합니다. 암호학적 난제 가정을 게임 인터페이스에 두는 것과 별개로, 컴파일된 AArch64 암호 구현(`HACL*`·`Fiat-Crypto`·`s2n-bignum`의 구현 검증 영역)과 `Drop::drop` 2개의 컴파일러 dead-store 소거 유지 여부·캐시·타이밍 부채널 누출은 검증 범위 밖입니다.
3. 원고·`DEVIATIONS.md` 자체 공시 하네스 경계(고정 시계·0 패딩 난수기·동기식 단일 파일): 실제 Signal 앱은 OS 난수기, 실시간 시계, 멀티스레드 비동기 SQLCipher DB, 네트워크 재전송 위에서 동작합니다. DeepMind가 원고·`DEVIATIONS.md`에 자체 공시한 범위(Tier 2) 위에서 검증 대상 CLI는 `Coins` 0 패딩 구조체, 1970년 1월 1일(`UNIX_EPOCH`, `DEV-PQ8`) 고정 시계(30일 만료 로직 `DEV-PQ9` 우회), 닫힌 표준입출력(`EBADF = 9`) EOF 처리를 씁니다.
4. 부팅 전 5바이트 수술, udf #0 스텁, OutOfMemory 면책: Eval.lean이 MRS 명령에서 정지하므로 부팅 전 .data 5바이트를 0으로 덮어쓰고, 링커 검증기([alink_check.py](../proofs/oai_ref/scripts/stock-pin/alink_check.py#L21-L31))는 미정의 외부 심볼과 약한 원자 연산 3종을 4바이트 udf #0(0x00000000) 트랩 스텁으로 채웁니다. 또한 Mmap.lean은 1 GiB 초과 시 -ENOMEM 반환 대신 .OutOfMemory로 정지해 널 포인터 역참조 경로를 면책합니다.
5. 양자내성 비주장(DEV-PQ19)과 $2^{40}$ 쿼리 표준 모델 공허화: "PQXDH + SPQR"이라는 프로토콜 이름과 달리 계산적 정리는 고전 안전성만 다루며, 배포 규모 $q_{\mathrm{total}} = 2^{40}$에서는 리덕션 스텝 예산이 $2^{96.00}$에 달해 표준 모델 Curve25519 4-leg GapDH 항이 $17,441 / 16,384 > 1$로 공허해집니다(저자들도 PQXDH.md:107-115에서 $2^{40}$ 구체적 보안 대입 불가를 시인하고 $q_{\mathrm{total}} \le 2^{24}$로 후퇴). 또한 단일 키 X25519+XEdDSA 공유(DEV-PQ13)의 GapSigEufCma와 GapDhWithSign Forking-Lemma 제곱근 손실은 독립 모듈 XeddsaRom/과 함께 Lean TCB 밖에 남아 있고, DEV-PQ16은 소수 위수 부분군 검사(P.isCanonical)를 강제(바이너리에서는 비틀림 검사를 훅으로 대체)하는 반면 DEV-PQ17은 코팩터-8 비틀림 동치류(pow8)로 감축하여([DEVIATIONS.md](../proofs/oai_ref/Computational/docs/DEVIATIONS.md#L1894-L1922)) $O(q_{\text{total}}^2)$ DDH 오라클 예산을 요구합니다.
6. 두 개의 운영 절벽 (35,211개 메시지와 56,680회 핸드셰이크): 8바이트 절단 와이어 MAC 때문에 SPQR V1 합성 상한(DEV-C14)은 $q_{\mathrm{ep}} = q$에서 $q = 35,211$개 메시지부터 1을 넘으며(16바이트 MAC 확장 시 $q = 2,307,621,357 > q_{\mathrm{u32,\max}}$로 단일 세션 공허화 완전 제거), .base-keys 파일은 56,680번째 핸드셰이크가 $2,097,160$바이트($> 2$ MiB)를 기록한 직후 56,681번째 핸드셰이크부터 미회전 최후수단 Kyber 프리키 수락이 영구 거부 상태에 빠집니다.
