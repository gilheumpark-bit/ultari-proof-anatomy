- 대상 독자: 해석적 정수론, 디리클레 급수, 또는 Lean 4 형식화에 익숙하며, 독립 `ShortDraft` 목표가 왜 $\text{Re}(s) > 23/24$에서 멈췄는지, `CubicGauss`의 비선형 체 점화식이 어떻게 모든 $n \in \mathbb{N}$에서 풀리는지, 그리고 제1부(7/8 ShortDraft 감사)·제2부(심판관·비묶음 그람 감사)·제3부(11/12 및 CubicGauss 통합)가 어떻게 연결되는지 코드 수준에서 추적하고 싶은 분.
- 범위 및 원문 출처 명시: [proofs/oai_ref/](../proofs/oai_ref/Endpoint.lean)에 포함되지 않은 업스트림 파일은 `openai/math` 저장소(커밋 `4eaee87` / `PR #70` `ca28f20`)에 속합니다. 아울러 `#003`의 증명된 주정리 `SevenEighths.lean`($\beta = 7/8 = 21/24$, `0 sorry`)이 이미 $\text{Re}(s) > 11/12$와 $\text{Re}(s) > 23/24$를 논리적으로 모두 함의하며, 가변 스케일 모듈 `DescentScale.lean`도 저장소에 이미 존재합니다. 따라서 본 보고서의 `ElevenTwelfths`(`23/24` 대 `11/12`) 및 미연결 30개 `CubicGauss` 분석은 `#003`이 $11/12$에 도달하지 못했다는 주장이 아니라 엄밀한 **모듈 층위(module-stratigraphy) 및 중간 목표 분석**입니다.

### 1.1 평균제곱 공식과 하드코딩된 $\sigma = 1/10$ 사슬 추적

`preprints/The-Quasi-Riemann-Hypothesis-October-5-2026/build/paper2.tex` (L680–724, `openai/math` 커밋 `4eaee87` / `PR #70` `ca28f20`)의 Proposition 2.1은 모든 행 $0 < \mathcal{N}(u) \le H = D^{1+\vartheta}$ 위에서 6차 꼬임 아이젠슈타인 뫼비우스 합 $A_u(D)$의 평균제곱 추정치를 확립합니다:
$$\sum_{0 < \mathcal{N}(u) \le D^{1+\vartheta}} \lvert A_u(D)\rvert^2 \ll D^{2+\vartheta+2\eta}.$$
꼬이지 않은 합 $A_1(D)$를 검출하기 위해 크기 $Y = H^{1/6} = D^{\alpha}$($\alpha = \frac{1+\vartheta}{6}$)의 증폭기 위에서 6제곱 상호법칙 마스크 $\chi_I(b^6) = \mathbf{1}_{(b, I)=1}$을 사용합니다. $b$ 위에서 코시-슈바르츠 부등식을 적용하면 분자 크기 $\sqrt{Y \cdot D^{2+\vartheta+2\eta}} = D^{\frac{2+\vartheta+\alpha}{2} + \eta}$를 얻고, 이를 증폭기 질량 $Y = D^\alpha$로 나누면 다음 지수 법칙이 나옵니다([thm_02_symbolic_sixth_power_cauchy_schwarz_exponent](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L44-L55)):
$$E_{\mathrm{CS}}(\vartheta) = \frac{2 + \vartheta - \alpha}{2} = \frac{2 + \vartheta - \frac{1+\vartheta}{6}}{2} = \frac{11 + 5\vartheta}{12}.$$

독립 서브모듈 `ShortDraft.DirichletTarget`이 $\text{Re}(s) > \frac{23}{24}$에서 멈춘 경위는 네 단계 매개변수 연쇄로 추적됩니다:
1. `CubicSieve/ClosedRecursion.lean:120`이 이차 잉여 기호 하강 단계에서 분모 `denominator = 1000`과 예비 여백 $\text{reserve} = \frac{1}{20} = 50/1000$을 상수로 고정했습니다.
2. `MeanSquare/ThetaDensity.lean:93` (`HasInitialCanonicalDensityAtRadius.nonzero_source_bound` / `exists_C_theta_density`)에 `(hσ : (1 : ℝ)/20 < σ)` 하한선이 박혔습니다.
3. `Mellin/SixthPowerAverage.lean:331` (`outside_totient_moebius_bound`)가 $\sigma > \frac{1}{20}$을 만족시키기 위해 $\sigma = \vartheta = 1/10$을 대입했습니다.
4. `PrimeRows/NormFiberExtraction.lean:343` (`exists_good_dyadic_scale_zpow`)에서 $H = Z^{11/10}$, $Y = Z^{11/60}$이 결정되어 다음 지수가 고정되었습니다(L370–406, [thm_01_shortdraft_fixed_reserve_and_23_24_exponent](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L25-L38)):
   $$\frac{1}{2}\left(\frac{11}{60} + 1 + \frac{11}{10}\right) = \frac{137}{120}, \qquad \frac{137}{120} - \frac{11}{60} = \frac{115}{120} = \frac{23}{24} = \frac{11 + 5(1/10)}{12}.$$

### 1.2 `CanonicalDescentScale`과 $(\vartheta, \eta) = (6\varepsilon/5, \varepsilon/2)$ 스케일링

고정된 $(1000, \frac{1}{20})$ 쌍을 `CanonicalDescentScale` (`50 ≤ reserve * denominator`, `openai/math` 저장소의 `DescentScale.lean` 및 `AlexKontorovich/quasi-rh`에 포함)로 교체해 $\kappa = \vartheta/2$, $D = \lceil 100/\vartheta \rceil + 1$을 택하면 임의의 $\vartheta > 0$가 허용됩니다([thm_04_canonical_descent_scale_budget_unlocks_arbitrary_theta](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L76-L92)). 목표 여백 $\varepsilon \in (0, 1/12)$에서 $\vartheta = \frac{6}{5}\varepsilon$, $\eta = \frac{1}{2}\varepsilon$를 설정하면([thm_03_kontorovich_epsilon_split_exact_11_12](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L60-L70)):
$$E_{\mathrm{CS}}\!\left(\frac{6}{5}\varepsilon\right) + \frac{1}{2}\varepsilon = \frac{11 + 6\varepsilon}{12} + \frac{6\varepsilon}{12} = \frac{11}{12} + \varepsilon$$
을 정확히 얻으며, 나머지 지수 $E_{\mathrm{rem}}(\vartheta) = \frac{5-\vartheta}{6}$은 엄격히 열세를 유지합니다([thm_05_remainder_exponent_subdominance_and_crossover](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L98-L110)). 또한 매끄러운 고리 영역의 모든 아이젠슈타인 정수 $b$ 위에서 $b^6$ 가중 평균을 취하면(`cauchy_const = 6 * 128 = 768`), 방사형 포아송 합으로 오일러 피 가중치 $\prod_{\mathfrak{p}\mid I}(1 - \mathcal{N}(\mathfrak{p})^{-1})$가 산출되어 란다우의 소 아이디얼 정리($J \asymp Y/\log Y$)를 거치지 않고 처리할 수 있습니다([thm_06_sixth_power_fiber_cauchy_constant_768](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L116-L126), [thm_07_totient_euler_correction_vs_prime_amplification_tradeoff](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L132-L142), [thm_08_part_one_paper_tex_table_vs_shortdraft_gap](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L148-L161)).

## 2. 제2기둥: 미연결 `OAI/NumberTheory/CubicGauss/` (30개 파일, 6,252줄) 해독

`lean/OAI/NumberTheory/CubicGauss/` 디렉터리(`openai/math` 커밋 `4eaee87` / `PR #70` `ca28f20`; 30개 Lean 파일, 총 6,252줄, 0 sorry)는 `CubicGauss/Recurrence.lean:350–370`과 `CubicGauss/LargeSieve.lean:15–190`에서 날카로운 3차 큰 체 부등식 `cubic_large_sieve`를 무조건부로 증명합니다. 그러나 `DirichletL/`(2,926개 파일)이나 `CubicMoment/`(3,549개 파일)에서는 `CubicGauss`를 단 한 줄도 import하지 않았습니다([thm_15_unimported_cubic_gauss_vs_bundled_cubic_gram_gap](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L297-L311)).

- `sieveThreshold`와 `sieveStep` ([thm_09_cubic_gauss_sieve_step_and_threshold_identities](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L173-L185)):
  $$\text{sieveThreshold}(\alpha) = \frac{6\alpha - 5}{3\alpha - 1}, \qquad \text{sieveStep}(\alpha) = \frac{6\alpha - 4}{3\alpha - 1}.$$
- 이차 여유분, 뫼비우스 공액 선형화, 그리고 유효한 점근 단순화 ([thm_10_cubic_gauss_quadratic_slack_and_attracting_fixed_point](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L190-L209), [thm_11_mobius_conjugacy_exact_closed_form_solution](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L214-L232)):
  뫼비우스 변환 $u(\alpha) = \frac{\alpha - 4/3}{\alpha - 1}$을 도입하면 비선형 유리 사상은 오차 0의 선형 등비수열로 환원됩니다:
  $$u(\text{sieveStep}(\alpha)) = \frac{2}{3}\,u(\alpha), \qquad \tilde{\alpha}_n = \frac{\frac{4}{3} - \left(\frac{2}{3}\right)^{n+1}}{1 - \left(\frac{2}{3}\right)^{n+1}} \xrightarrow{n\to\infty} \frac{4}{3}.$$
  한편 OpenAI의 `CubicGauss/LargeSieve.lean:75`는 기하급수 상계 $\alpha_n = \frac{4}{3} + \left(\frac{2}{3}\right)^{n+1}$을 사용합니다([thm_12_nonlinear_vs_linearized_sieve_iterates_comparison](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L237-L254)). 두 수열 모두 정확히 동일한 점근 고정점 $\alpha^{\ast} = \frac{4}{3}$에 수렴하므로, `LargeSieve.lean:75`의 기하급수 상계는 극한 $\alpha^{\ast} = 4/3$을 얻기 위한 유효한 단순화입니다(유한 $n$에서의 초과분 $\alpha_n - 4/3$만 3배 차이 남). $\alpha^{\ast} = 4/3$을 3차 상호법칙(`short_four_thirds`, [thm_13_short_four_thirds_and_reciprocity_symmetrization](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L260-L272), [thm_14_scalar_bounds_epsilon_and_mixed_exponents](../proofs/qrh_eleven_twelfths_and_cubic_large_sieve.lean#L278-L290))과 결합하면 날카로운 $M + N + (MN)^{2/3}$ 상계를 얻습니다.

## 3. 제3·4기둥: $\mathbb{Q}(\sqrt{921})$ 대수적 통합과 매개변수 파카스 결합 해제

$$R(d, u) = 1 - d + \frac{(5/6 - d)\,d\,P(u)}{2\,J(d, u)}.$$
최악의 이진 절단면 $u = 1/2$에서 $R(d, 1/2) = 2/3$은 이차방정식 $288\,d^2 - 588\,d + 185 = 0$으로 환원되며, $(3/8, 5/6)$ 구간의 근은 $\delta_c = \frac{49 - \sqrt{921}}{48} \approx 0.388585$입니다([thm_16_shared_critical_quadratic_288_588_185_and_count_2_3](../proofs/qrh_q_sqrt_921_farkas_and_unbundling_synthesis.lean#L24-L42)).

## 4. 제5기둥: 전 구간 수학적 귀납법(`induction n`), $\mathbb{Z}[\sqrt{921}]$ 정역, 그리고 준리만 가설 3단계 통합 브리지

[proofs/qrh_trilogy_induction_and_algebraic_bridge.lean](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean)(정리 31–45)에서는 유한 단계 검증을 넘어 전 구간 수학적 귀납법과 3부작 대수적 브리지를 구축했습니다:
- 모든 $n \in \mathbb{N}$에서의 `sieveIter` 수학적 귀납법 (`induction n`): 재귀함수 `sieveIter : Nat → Nat × Nat`의 $3p_n - 4q_n = 2^{n+1}$ 및 $p_n - q_n = 3^n$ 불변량을 귀납법으로 증명하고([thm_31_sieve_iter_mobius_invariants_by_induction](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L36-L69)), 닫힌 해 $p_n = 4\cdot 3^n - 2^{n+1}$, $q_n = 3\cdot 3^n - 2^{n+1}$([thm_32_sieve_iter_exact_closed_form_all_n](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L73-L86))과 분모 격차 $9\cdot 3^n - 3q_n = 3\cdot 2^{n+1}$([thm_33_sieve_iter_strictly_beats_openai_sieve_exponent_all_n](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L92-L107))을 증명했습니다.
- 이차 정역 $\mathbb{Z}[\sqrt{921}]$ 구조체 (`structure ZSqrt921`): 환 곱셈 `z921Mul`, 켤레 `z921Conj`, 노름 `z921Norm`을 정의하여 $48\delta_c = \langle 49, -1\rangle$의 근 항등식([thm_34_zsqrt921_norm_and_critical_quadratic_root](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L130-L138))과 유리화·격차 노름 $-5567304 < 0$([thm_35_zsqrt921_liu_rationalization_and_case005_gap](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L144-L157))을 증명했습니다.
- $3264 \leftrightarrow 4896 \leftrightarrow 215 \leftrightarrow 44064$ 3부작 대수적 브리지 (제1부 + 제2부 + 제3부):
  1. 제1부의 소수 기울기 17이 $17 \times 96 = 1632 = \gcd(3264, 4896)$을 생성하며, 제1부 분모 $d_{\mathrm{I}} = 2 \times 1632 = 3264$와 제2부 분모 $d_{\mathrm{II}} = 3 \times 1632 = 4896$이 성립합니다([thm_36_trilogy_denominator_bridge_3264_and_4896](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L167-L178)).
  2. 제1부의 여백 $\frac{215}{3264}$($\delta_{\max} = \frac{15}{34}$)에 3차 체 가중치 $\frac{2}{3}$를 곱하면 정확히 제2부의 3항 비예외 이동폭 $\frac{7}{8} - \frac{4069}{4896} = \frac{215}{4896}$이 됩니다([thm_37_case001_margin_215_3264_drives_case005_4069_4896](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L185-L205), [thm_38_case001_unbundling_breaks_case008_farkas_wall](../proofs/qrh_trilogy_induction_and_algebraic_bridge.lean#L212-L225)).
